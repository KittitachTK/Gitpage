## 0.0 คำถามตั้งต้น

แคลคูลัสทั้งเล่มตั้งอยู่บนประโยคแบบนี้:

> "ให้ f ต่อเนื่องบน [a,b] แล้ว **มี** c ที่..."

คำว่า **"มี"** คือคำที่แพงที่สุดในวิชานี้ เพราะมันไม่ได้ตามมาจากพีชคณิต ไม่ได้ตามมาจากเรขาคณิต และไม่ได้ตามมาจากสามัญสำนึก มันตามมาจาก **สัจพจน์เดียว** ที่บอกว่าเส้นจำนวนจริง "ไม่มีรู"

ชั้นนี้ทำสามอย่าง:
1. แสดงว่า ℚ พังตรงไหน (ทำไมต้องมี ℝ)
2. ระบุสัจพจน์ที่อุดรูนั้น และพิสูจน์ว่ามันมีรูปสมมูลอีก 6 รูป
3. ชี้ว่าทฤษฎีบทแต่ละตัวในแคลคูลัสใช้รูปไหน

## 0.1 ℚ พังตรงไหน — สี่หลักฐาน

ℚ เป็นสนามอันดับที่หนาแน่น (ระหว่างสองจำนวนตรรกยะใด ๆ มีจำนวนตรรกยะเสมอ) ดูเหมือนสมบูรณ์แบบ แต่:

**หลักฐาน 1 — IVT พังบน ℚ**
ให้ f(x) = x² − 2 บน ℚ ∩ [1,2]
f ต่อเนื่อง (ในความหมาย ε–δ ที่จำกัดบน ℚ), f(1) = −1 < 0 < 2 = f(2)
แต่ **ไม่มี** c ∈ ℚ ที่ f(c) = 0 เพราะ √2 ∉ ℚ

**หลักฐาน 2 — EVT พังบน ℚ**
ให้ g(x) = 1/(x² − 2) บน ℚ ∩ [0,2]
g ต่อเนื่องทุกจุดของโดเมน (ตัวส่วนไม่เคยเป็นศูนย์ใน ℚ!) แต่ **ไม่มีขอบเขต** — พุ่งขึ้นอนันต์เมื่อเข้าใกล้ √2
บนช่วง "ปิดและมีขอบเขต" ของ ℚ ที่ควรจะเป็นเซตกระชับ

**หลักฐาน 3 — sup ไม่มีอยู่**
S = {x ∈ ℚ : x² < 2} ไม่ว่าง มีขอบเขตบน (เช่น 2) แต่ **ไม่มีขอบเขตบนน้อยสุดใน ℚ**
ทุกขอบเขตบนตรรกยะสามารถทำให้เล็กลงได้เสมอ

**หลักฐาน 4 — ลำดับโคชีไม่ลู่เข้า**
1, 1.4, 1.41, 1.414, 1.4142, ... เป็นลำดับโคชีใน ℚ แต่ไม่ลู่เข้าสู่จุดใดใน ℚ

**บทสรุป:** ทั้งสี่หลักฐานคือ *อาการเดียวกัน* — ℚ มี "รู" อยู่ที่ตำแหน่งของจำนวนอตรรกยะ และหลักฐานทั้งสี่จะกลายเป็นข้อความสมมูลกันใน §0.6

## 0.2 โครงกระดูกพีชคณิต: สนามอันดับ (Ordered Field)

ก่อนถึงความบริบูรณ์ ℝ ต้องมีโครงสร้างพื้นฐานก่อน สัจพจน์แบ่งเป็นสามชุด

### ชุด A — สัจพจน์สนาม (Field Axioms)
สำหรับ +, × บนเซต F:

| # | สัจพจน์ | + | × |
|---|---|---|---|
| A1 | การปิด | a+b ∈ F | ab ∈ F |
| A2 | การสลับที่ | a+b = b+a | ab = ba |
| A3 | การเปลี่ยนหมู่ | (a+b)+c = a+(b+c) | (ab)c = a(bc) |
| A4 | เอกลักษณ์ | ∃0 : a+0 = a | ∃1≠0 : a·1 = a |
| A5 | ตัวผกผัน | ∃(−a) : a+(−a) = 0 | a≠0 ⟹ ∃a⁻¹ |
| A6 | การแจกแจง | a(b+c) = ab + ac | |

### ชุด B — สัจพจน์อันดับ (Order Axioms)
มีเซต P ⊂ F ("จำนวนบวก") ที่:
- **B1 (ไตรวิภาค)** ทุก a ∈ F เป็นจริงข้อเดียวเท่านั้น: a ∈ P, a = 0, −a ∈ P
- **B2** a, b ∈ P ⟹ a + b ∈ P
- **B3** a, b ∈ P ⟹ ab ∈ P

นิยาม a < b ⟺ b − a ∈ P

**ผลพวงทันที** (พิสูจน์จาก A + B ล้วน ไม่ต้องใช้ความบริบูรณ์):
- a² ≥ 0 สำหรับทุก a ⟹ 1 > 0 ⟹ **สนามอันดับต้องมีลักษณะเฉพาะเป็นศูนย์และบรรจุ ℚ เสมอ**
- **อสมการสามเหลี่ยม** |a+b| ≤ |a| + |b| ← เครื่องมือที่ใช้ทุกครั้งที่พิสูจน์ ε–δ
- ℂ **ไม่สามารถ** เป็นสนามอันดับได้ (เพราะ i² = −1 < 0 ขัดกับ a² ≥ 0)

**⚠️ จุดสำคัญ:** ℚ สอดคล้องสัจพจน์ทั้ง A และ B ครบถ้วน **ดังนั้นชุด A+B ยังแยก ℝ จาก ℚ ไม่ได้เลย**

## 0.3 สัจพจน์ความบริบูรณ์ (ชุด C)

### นิยามที่ต้องมีก่อน

ให้ S ⊆ ℝ ไม่ว่าง
- **b เป็นขอบเขตบนของ S** ⟺ ∀x ∈ S : x ≤ b
- **s = sup S (ขอบเขตบนน้อยสุด)** ⟺ (i) s เป็นขอบเขตบน (ii) ถ้า b เป็นขอบเขตบนใด ๆ แล้ว s ≤ b
- นิยาม inf (ขอบเขตล่างมากสุด) แบบสมมาตร

### สัจพจน์ C (Least Upper Bound Axiom / Completeness)
> **ทุกเซตย่อยของ ℝ ที่ไม่ว่างและมีขอบเขตบน มี supremum อยู่ใน ℝ**

**ทั้งวิชาแคลคูลัสวางอยู่บนบรรทัดนี้บรรทัดเดียว**

### บทตั้งลักษณะเฉพาะของ sup (ε-Lemma) — เครื่องมือทำงานจริง
> s = sup S ⟺ (i) s เป็นขอบเขตบน **และ** (ii) ∀ε > 0 ∃x ∈ S : x > s − ε

**พิสูจน์ (⟸):** ถ้า b < s เป็นขอบเขตบน ให้ ε = s − b > 0 จาก (ii) ได้ x ∈ S ที่ x > s − ε = b ขัดแย้งกับ b เป็นขอบเขตบน ∎

**ทำไมข้อนี้สำคัญ:** นิยาม sup เป็นข้อความเชิงตรรกะที่ใช้ยาก แต่ ε-Lemma แปลงมันเป็น **"เข้าใกล้ s ได้เท่าไรก็ได้จากข้างใน S"** ซึ่งเป็นรูปที่เข้ากับนิยาม ε–δ ได้พอดี — บทพิสูจน์เกือบทุกอันในชั้น 0 ใช้บทตั้งนี้

### ทฤษฎีบทเอกภาพ (Categoricity)
> **ℝ คือสนามอันดับบริบูรณ์เพียงหนึ่งเดียว ขึ้นกับสมสัณฐาน (isomorphism)**

สนามอันดับใดก็ตามที่สอดคล้อง A + B + C จะต้องสมสัณฐานกับ ℝ อย่างเดียวเท่านั้น

**นัยเชิงปรัชญา:** ℝ ไม่ใช่ "สิ่งที่เราเลือกสร้างขึ้น" แต่เป็น **สิ่งที่ถูกบังคับให้เป็นแบบนั้น** โดยสัจพจน์สามชุด — คำถาม "จำนวนจริงคืออะไร" จึงมีคำตอบเดียว

`⇢ Model Theory: categoricity, second-order logic (สัจพจน์ C เป็นข้อความอันดับสอง เพราะควอนติฟายบนเซต ไม่ใช่บนสมาชิก)`

## 0.4 การสร้าง ℝ — สองเส้นทาง

สัจพจน์บอกว่า ℝ *มีสมบัติอะไร* แต่ไม่ได้บอกว่า *มีอยู่จริงไหม* — ต้องสร้างจาก ℚ

### เส้นทาง A — รอยตัดเดเดคินด์ (Dedekind Cuts, 1872)
**ความคิด:** จำนวนจริงคือ *ตำแหน่งของรอยตัด* บนเส้นจำนวนตรรกยะ

นิยาม: รอยตัดคือเซต α ⊂ ℚ ที่
1. α ≠ ∅, α ≠ ℚ
2. ปิดลง: p ∈ α, q < p ⟹ q ∈ α
3. ไม่มีสมาชิกมากสุด

แล้ว ℝ := เซตของรอยตัดทั้งหมด เรียงลำดับด้วย ⊆

**ความงามของวิธีนี้:** สัจพจน์ความบริบูรณ์กลายเป็น **ทฤษฎีบทที่พิสูจน์ได้ในบรรทัดเดียว** — ถ้า 𝒜 เป็นเซตของรอยตัดที่มีขอบเขตบน แล้ว `sup 𝒜 = ⋃𝒜` (ยูเนียน) ซึ่งเป็นรอยตัดเอง
> ความบริบูรณ์ = ความจริงที่ว่ายูเนียนของเซตยังคงเป็นเซต

**ข้อเสีย:** นิยามการคูณยุ่งยากมาก (ต้องแยกกรณีเครื่องหมาย)

### เส้นทาง B — การเติมเต็มด้วยลำดับโคชี (Cantor)
**ความคิด:** จำนวนจริงคือ *สิ่งที่ลำดับโคชีพยายามจะเข้าใกล้*

ℝ := {ลำดับโคชีใน ℚ} / ~ โดย (aₙ) ~ (bₙ) ⟺ aₙ − bₙ → 0

**ความงามของวิธีนี้:** การบวกและคูณนิยามทีละพจน์ ง่ายมาก
**ความสำคัญที่ยิ่งกว่า:** วิธีนี้ **ขยายไปใช้กับปริภูมิเมตริกใดก็ได้**

```
เติมเต็ม ℚ ด้วยค่าสัมบูรณ์ปกติ        →  ℝ
เติมเต็ม ℚ ด้วยค่าสัมบูรณ์ p-adic     →  ℚₚ    ⇢ ทฤษฎีจำนวน
เติมเต็มพหุนามด้วยนอร์มยูนิฟอร์ม      →  C[a,b] ⇢ การวิเคราะห์เชิงฟังก์ชัน
เติมเต็ม C[a,b] ด้วยนอร์ม L²          →  L²    ⇢ ปริภูมิฮิลเบิร์ต, กลศาสตร์ควอนตัม
```

**ทฤษฎีบทออสตรอฟสกี:** ค่าสัมบูรณ์บน ℚ มีเพียงสองชนิดเท่านั้น — แบบปกติ กับแบบ p-adic
⟹ **ℝ และ ℚₚ คือการเติมเต็ม ℚ ที่เป็นไปได้ทั้งหมดในจักรวาล**

### ทั้งสองเส้นทางให้ผลสมสัณฐานกัน
โดยทฤษฎีบทเอกภาพใน §0.3 — ไม่สำคัญว่าคุณสร้างด้วยวิธีไหน ผลลัพธ์คือวัตถุเดียวกัน

## 0.5 ผลพวงชุดแรก

### ทฤษฎีบท 0.5.1 — สมบัติอาร์คิมีดีส
> ℕ ไม่มีขอบเขตบนใน ℝ · สมมูลกับ: ∀x ∈ ℝ ∃n ∈ ℕ : n > x

**พิสูจน์**
สมมติตรงข้าม: ℕ มีขอบเขตบน เนื่องจาก ℕ ≠ ∅ สัจพจน์ C ให้ s = sup ℕ
เนื่องจาก s − 1 < s ตาม ε-Lemma (ε = 1) มี n ∈ ℕ ที่ n > s − 1
ดังนั้น n + 1 > s แต่ n + 1 ∈ ℕ — ขัดแย้งกับ s เป็นขอบเขตบนของ ℕ ∎

**ผลพวง**
- (a) ∀ε > 0 ∃n ∈ ℕ : 1/n < ε ⟹ **1/n → 0**
- (b) ∀x > 0, y ∈ ℝ ∃n : nx > y (หลักการ "ตวงมหาสมุทรด้วยช้อนได้")
- (c) ไม่มี "จำนวนน้อยที่สุดที่มากกว่าศูนย์" ⟹ **ℝ ไม่มีอนันตภาคเล็ก (infinitesimal)**

**⚠️ ข้อควรระวังที่สำคัญมาก:** อาร์คิมีดีส **ไม่ใช่** ผลจากสัจพจน์ A+B เท่านั้น — มันต้องใช้ C
มีสนามอันดับที่ **ไม่เป็นอาร์คิมีดีส** อยู่จริง (เช่น สนามของฟังก์ชันตรรกยะเรียงตามพฤติกรรมที่อนันต์) ในสนามพวกนั้นมีสมาชิกที่ "ใหญ่กว่าจำนวนธรรมชาติทุกตัว" อยู่จริง
`⇢ Non-standard Analysis: hyperreals *ℝ ซึ่งอนุพันธ์นิยามด้วย dx ที่เล็กแต่ไม่เป็นศูนย์จริง ๆ — คือการทำให้สัญชาตญาณของไลบ์นิซถูกต้องตามหลักตรรกะ`

### ทฤษฎีบท 0.5.2 — ความหนาแน่นของ ℚ ใน ℝ
> ∀x < y ใน ℝ ∃q ∈ ℚ : x < q < y

**พิสูจน์**
จากอาร์คิมีดีส เลือก n ที่ n > 1/(y−x) ⟹ 1/n < y − x
ให้ m เป็นจำนวนเต็มน้อยสุดที่ m > nx (มีอยู่จริงจากอาร์คิมีดีส + หลักการจัดอันดับดีของ ℤ)
ดังนั้น m − 1 ≤ nx < m ⟹ x < m/n ≤ x + 1/n < x + (y−x) = y ∎

**ผลพวงคู่:** จำนวนอตรรกยะก็หนาแน่นใน ℝ (ใช้ q + √2/n)

**⚠️ อย่าสับสน:** *หนาแน่น* (ไม่มีช่องว่างที่วัดได้) ≠ *บริบูรณ์* (ไม่มีรู) — ℚ หนาแน่นในตัวเองแต่ไม่บริบูรณ์ นี่คือความแตกต่างที่ละเอียดที่สุดในชั้นนี้

### ทฤษฎีบท 0.5.3 — การมีอยู่ของ √2
> ∃! s > 0 : s² = 2

**พิสูจน์**
S = {x ∈ ℝ : x ≥ 0, x² < 2} · S ≠ ∅ (1 ∈ S) และ 2 เป็นขอบเขตบน ⟹ s = sup S มีอยู่
- ถ้า s² < 2: เลือก h = min{1, (2−s²)/(2s+1)} > 0 จะได้ (s+h)² < 2 ⟹ s+h ∈ S ขัดแย้งกับ s เป็นขอบเขตบน
- ถ้า s² > 2: เลือก h = (s²−2)/(2s) > 0 จะได้ (s−h)² > 2 ⟹ s−h เป็นขอบเขตบน ขัดแย้งกับ s เป็นตัวน้อยสุด

ไตรวิภาค ⟹ s² = 2 ∎

**นี่คือแม่แบบของบทพิสูจน์การมีอยู่ทุกอันในแคลคูลัส:** สร้างเซตที่เหมาะสม → เอา sup → ตัดกรณี > และ < ด้วยข้อขัดแย้ง → เหลือ =
**IVT ในบทที่ 1 ของ Anton ก็ใช้โครงนี้เป๊ะ ๆ** เพียงแต่เปลี่ยน x² − 2 เป็น f(x) ทั่วไป

### ทฤษฎีบท 0.5.4 — ℝ นับไม่ได้
จากสมบัติช่วงซ้อน (§0.6): ℝ นับไม่ได้ ในขณะที่ ℚ นับได้
⟹ **"เกือบทุก" จำนวนจริงเป็นอตรรกยะ** และยิ่งกว่านั้น เกือบทุกตัวเป็น transcendental
`⇢ ทฤษฎีเซต: |ℝ| = 2^ℵ₀, สมมติฐานความต่อเนื่อง (Cohen: เป็นอิสระจาก ZFC)`

## 0.6 วงแหวนแห่งความสมมูล — เจ็ดหน้ากากของสิ่งเดียวกัน

**นี่คือทฤษฎีบทที่สำคัญที่สุดของชั้นนี้** ข้อความเจ็ดข้อต่อไปนี้ ในสนามอันดับใด ๆ **สมมูลกันทั้งหมด**

| # | ชื่อ | ข้อความ |
|---|---|---|
| **(1)** | ขอบเขตบนน้อยสุด | เซตไม่ว่างที่มีขอบเขตบน มี sup |
| **(2)** | ลำดับโมโนโทน (MCT) | ลำดับเพิ่มที่มีขอบเขตบน ลู่เข้า |
| **(3)** | ช่วงซ้อน (Nested Interval) | ช่วงปิดซ้อนกัน I₁ ⊇ I₂ ⊇ ... ⟹ ⋂Iₙ ≠ ∅ |
| **(4)** | โบลซาโน–ไวเออร์ชตราสส์ | ลำดับที่มีขอบเขต มีลำดับย่อยลู่เข้า |
| **(5)** | ความบริบูรณ์แบบโคชี | ลำดับโคชีทุกลำดับลู่เข้า |
| **(6)** | ไฮเนอ–โบเรล | [a,b] กระชับ (คลุมเปิดทุกอันมีคลุมย่อยจำกัด) |
| **(7)** | ความเชื่อมโยง | ℝ เชื่อมโยง (แยกเป็นสองเซตเปิดไม่ว่างที่ไม่ตัดกันไม่ได้) |

> **หมายเหตุทางเทคนิค:** (3) และ (5) ต้องพ่วงสมบัติอาร์คิมีดีสด้วยจึงจะย้อนกลับไป (1) ได้ — มีสนามที่บริบูรณ์แบบโคชีแต่ไม่เป็นอาร์คิมีดีส (สนาม Levi-Civita) และสนามนั้น **ไม่มี** สมบัติ LUB

### บทพิสูจน์แต่ละลูกศร

**(1) ⟹ (2) LUB ⟹ MCT**
ให้ (aₙ) เพิ่มและมีขอบเขตบน · เซต A = {aₙ : n ∈ ℕ} ไม่ว่างและมีขอบเขตบน ⟹ L = sup A
ให้ ε > 0 · ตาม ε-Lemma มี N ที่ a_N > L − ε
เนื่องจากลำดับเพิ่ม: n ≥ N ⟹ L − ε < a_N ≤ aₙ ≤ L < L + ε ⟹ |aₙ − L| < ε ∎

**(2) ⟹ (3) MCT ⟹ ช่วงซ้อน**
Iₙ = [aₙ, bₙ] ซ้อนกัน ⟹ (aₙ) เพิ่มและมีขอบเขตบนด้วย b₁; (bₙ) ลดและมีขอบเขตล่างด้วย a₁
MCT ⟹ aₙ → a, bₙ → b และ a ≤ b ⟹ [a,b] ⊆ ⋂Iₙ ≠ ∅ ∎
*(ถ้าเพิ่มเงื่อนไข |Iₙ| → 0 จะได้จุดร่วมเพียงจุดเดียว — ต้องใช้อาร์คิมีดีส)*

**(3) ⟹ (4) ช่วงซ้อน ⟹ Bolzano–Weierstrass**
(xₙ) มีขอบเขต ⟹ xₙ ∈ [a,b] ทุก n
แบ่ง [a,b] ครึ่ง — อย่างน้อยครึ่งหนึ่งต้องมีพจน์ของลำดับอยู่**จำนวนอนันต์ตัว** เลือกครึ่งนั้นเป็น I₁
ทำซ้ำได้ช่วงซ้อน I₁ ⊇ I₂ ⊇ ... โดย |Iₖ| = (b−a)/2ᵏ → 0
เลือก x_{n₁} ∈ I₁, x_{n₂} ∈ I₂ (n₂ > n₁) ไปเรื่อย ๆ — ทำได้เพราะแต่ละ Iₖ มีพจน์อนันต์ตัว
จุดร่วม c ของช่วงซ้อนคือลิมิตของลำดับย่อยนี้ ∎

> **สังเกตกลวิธี "แบ่งครึ่งแล้วเลือกครึ่งที่แย่"** — นี่คือเทคนิคเดียวกับที่ใช้พิสูจน์ EVT, Heine–Borel และวิธีแบ่งครึ่งหาราก (bisection) จำกลวิธีนี้ไว้ มันคือ *อัลกอริทึม* ที่ซ่อนอยู่ในทฤษฎีบทการมีอยู่

**(4) ⟹ (5) Bolzano–Weierstrass ⟹ ความบริบูรณ์แบบโคชี**
ขั้นที่ 1: ลำดับโคชีมีขอบเขต (เลือก ε = 1 ได้ N; พจน์หลัง N อยู่ในรัศมี 1 จาก a_N; พจน์ก่อน N มีจำนวนจำกัด)
ขั้นที่ 2: BW ⟹ มีลำดับย่อย x_{nₖ} → L
ขั้นที่ 3: **บทตั้งสำคัญ** — ลำดับโคชีที่มีลำดับย่อยลู่เข้า ต้องลู่เข้าทั้งลำดับ
 |xₙ − L| ≤ |xₙ − x_{nₖ}| + |x_{nₖ} − L| < ε/2 + ε/2 ∎

**(5) + อาร์คิมีดีส ⟹ (1) โคชี ⟹ LUB**
ให้ S ไม่ว่างมีขอบเขตบน · สร้างสองลำดับด้วยการแบ่งครึ่ง:
เริ่มจาก a₀ ที่ *ไม่ใช่* ขอบเขตบน และ b₀ ที่ *เป็น* ขอบเขตบน
แต่ละขั้นดูจุดกึ่งกลาง m — ถ้า m เป็นขอบเขตบน ให้ b := m มิฉะนั้น a := m
ได้ bₙ − aₙ = (b₀−a₀)/2ⁿ → 0 (อาร์คิมีดีส) ⟹ ทั้งสองเป็นลำดับโคชี ⟹ ลู่เข้าสู่ s เดียวกัน
แสดง s = sup S: s เป็นขอบเขตบน (เพราะ bₙ ↓ s เป็นขอบเขตบน) และไม่มีตัวเล็กกว่า (เพราะ aₙ ↑ s ไม่เป็นขอบเขตบน) ∎

**(1) ⟹ (6) LUB ⟹ ไฮเนอ–โบเรล**
ให้ 𝒰 เป็นคลุมเปิดของ [a,b]
S = {x ∈ [a,b] : [a,x] คลุมได้ด้วยสมาชิกจำนวนจำกัดของ 𝒰}
a ∈ S (เพราะ {a} อยู่ใน U บางตัว) และ b เป็นขอบเขตบน ⟹ c = sup S
- **c ∈ S:** c อยู่ใน U₀ ∈ 𝒰 บางตัว ซึ่งเปิด ⟹ (c−δ, c+δ) ⊆ U₀ · มี x ∈ S ที่ x > c−δ ⟹ [a,x] คลุมได้ด้วยจำนวนจำกัด บวก U₀ ⟹ [a,c] คลุมได้
- **c = b:** ถ้า c < b เราขยายไปถึง c + δ/2 ได้ด้วยชุดเดิม ขัดแย้งกับ c = sup ∎

**(6) ⟹ (4) ไฮเนอ–โบเรล ⟹ Bolzano–Weierstrass** *(สวนนิเสธ)*
ถ้า (xₙ) ⊂ [a,b] ไม่มีจุดสะสม แล้วทุก p ∈ [a,b] มีย่าน Vₚ ที่บรรจุพจน์ของลำดับจำนวนจำกัด
{Vₚ} เป็นคลุมเปิด ⟹ มีคลุมย่อยจำกัด ⟹ [a,b] บรรจุพจน์จำนวนจำกัด — ขัดแย้ง (ลำดับมีพจน์อนันต์) ∎

**(1) ⟹ (7) LUB ⟹ ความเชื่อมโยง / IVT**
ให้ f ต่อเนื่องบน [a,b], f(a) < 0 < f(b)
S = {x ∈ [a,b] : f(x) < 0} · a ∈ S, b เป็นขอบเขตบน ⟹ c = sup S
- ถ้า f(c) < 0: ความต่อเนื่อง ⟹ f < 0 บนย่านของ c ⟹ มีจุดใน S ที่มากกว่า c ⟹ ขัดแย้ง
- ถ้า f(c) > 0: ความต่อเนื่อง ⟹ f > 0 บน (c−δ, c] ⟹ c−δ เป็นขอบเขตบนที่เล็กกว่า ⟹ ขัดแย้ง

⟹ f(c) = 0 ∎ **นี่คือบทพิสูจน์ IVT ฉบับเต็มที่ Anton ละไว้**

**💡 Key Insight ของชั้น 0**
> ข้อความทั้งเจ็ดคือ **สิ่งเดียวกัน** ที่มองจากมุมต่างกัน
> - (1) มองแบบ **อันดับ** (order-theoretic)
> - (2)(4)(5) มองแบบ **ลำดับ** (sequential)
> - (3) มองแบบ **เรขาคณิต**
> - (6)(7) มองแบบ **โทโพโลยี**
>
> เวลาพิสูจน์ทฤษฎีบทในแคลคูลัส คุณ *เลือกหน้ากากที่สะดวกที่สุด* — และนี่คือเหตุผลที่บทพิสูจน์เดียวกันในตำราต่างเล่มดูไม่เหมือนกันเลย

## 0.7 ความกระชับ: สองนิยามที่แยกทางกันในภายหลัง

| นิยาม | ข้อความ | มาจากข้อไหน |
|---|---|---|
| **กระชับเชิงลำดับ** (sequentially compact) | ทุกลำดับมีลำดับย่อยลู่เข้าในเซต | (4) BW |
| **กระชับเชิงคลุม** (compact) | ทุกคลุมเปิดมีคลุมย่อยจำกัด | (6) Heine–Borel |

- **ใน ℝⁿ:** สมมูลกัน และสมมูลกับ "ปิด + มีขอบเขต" (ทฤษฎีบทไฮเนอ–โบเรล)
- **ในปริภูมิเมตริกทั่วไป:** ยังสมมูลกัน (แต่ "ปิด+มีขอบเขต" **ไม่พอ** แล้ว — ต้องเป็น "ปิด + มีขอบเขตเชิงเต็ม")
- **ในปริภูมิทอพอโลยีทั่วไป:** **ไม่สมมูลกัน** ⟹ ตรงนี้คือจุดที่โทโพโลยีแยกตัวออกจากการวิเคราะห์

`⇢ ทฤษฎีบทไทโคนอฟ (ผลคูณของเซตกระชับกระชับ) สมมูลกับสัจพจน์การเลือก — ความกระชับผูกกับรากฐานของทฤษฎีเซตโดยตรง`

### ทฤษฎีบท 0.7.1 — ไฮเนอ–คันทอร์ (ความต่อเนื่องเอกรูป)
> f ต่อเนื่องบนเซตกระชับ K ⟹ f ต่อเนื่องเอกรูปบน K
> (คือ δ เลือกได้โดยไม่ขึ้นกับตำแหน่ง x)

**พิสูจน์ (ใช้ BW)** สมมติไม่เอกรูป ⟹ ∃ε₀ > 0 และคู่ (xₙ, yₙ) ที่ |xₙ−yₙ| < 1/n แต่ |f(xₙ)−f(yₙ)| ≥ ε₀
BW ⟹ x_{nₖ} → c ∈ K และ y_{nₖ} → c ด้วย
ความต่อเนื่องที่ c ⟹ |f(x_{nₖ}) − f(y_{nₖ})| → 0 ขัดแย้งกับ ≥ ε₀ ∎

**ทำไมทฤษฎีบทนี้ถึงสำคัญที่สุดในชั้นนี้สำหรับแคลคูลัส:**
มันคือ **วัตถุดิบเดียว** ที่ใช้พิสูจน์ว่า *ฟังก์ชันต่อเนื่องบน [a,b] อินทิเกรตได้แบบรีมันน์*
เพราะการทำให้ผลบวกบน–ล่างเข้ามาชิดกันต้องการ δ ตัวเดียวที่ใช้ได้ทั้งช่วง — ซึ่งความต่อเนื่องธรรมดาให้ไม่ได้

```
ความบริบูรณ์ → BW → ไฮเนอ–คันทอร์ → ต่อเนื่อง ⟹ อินทิเกรตได้ → ปริพันธ์จำกัดเขตมีอยู่จริง → FTC
```
**นี่คือเส้นที่ยาวที่สุดในแผนที่ทั้งหมด และ Anton ข้ามมันทั้งเส้น**

## 0.9 ขอบเขตของ ℝ — ทางแยกสามสาย

ℝ บริบูรณ์แล้ว แต่ยังขาดสมบัติอื่น ๆ ซึ่งเป็นที่มาของสาขาใหม่

| ℝ ขาดอะไร | ทางแก้ | สาขาที่เกิด |
|---|---|---|
| **ไม่ปิดเชิงพีชคณิต** (x²+1=0 ไม่มีราก) | ขยายเป็น ℂ | ทฤษฎีบทหลักมูลของพีชคณิต, การวิเคราะห์เชิงซ้อน |
| **ไม่กระชับ** (±∞ หายไป) | ℝ̄ = [−∞,∞], การอัดแน่นแบบจุดเดียว | โทโพโลยี, ทฤษฎีการวัด |
| **ไม่มีอนันตภาคเล็ก** (อาร์คิมีดีส) | *ℝ (hyperreals) | การวิเคราะห์ไม่มาตรฐาน |
| **การเติมเต็มแบบอื่น** | ℚₚ | ทฤษฎีจำนวน, เรขาคณิตเชิงเลขคณิต |
| **มิติเดียว** | ℝⁿ, แมนิโฟลด์ | แคลคูลัส 3, เรขาคณิตเชิงอนุพันธ์ |
| **ปริพันธ์รีมันน์อ่อนแอเกินไป** | การวัดของเลอเบก | ทฤษฎีการวัด, ความน่าจะเป็น |

**หมายเหตุที่สวยงาม:** ℂ ปิดเชิงพีชคณิตแต่ *เรียงลำดับไม่ได้* — คุณได้อย่างเสียอย่างเสมอ
ℝ = สนามอันดับบริบูรณ์ · ℂ = สนามปิดเชิงพีชคณิต · **ไม่มีสนามที่เป็นทั้งสองอย่าง**

## 0.11 แบบฝึกหัดเชิงทฤษฎี

**ระดับที่ 1 — ตรวจความเข้าใจนิยาม**
1. หา sup และ inf ของ S = {1 − 1/n : n ∈ ℕ} · sup อยู่ใน S หรือไม่? แล้ว inf?
2. แสดงว่า sup ของเซตอาจไม่เป็นสมาชิกของเซต แต่ max ต้องเป็นเสมอ · เขียนเงื่อนไขที่ทำให้ sup S = max S
3. พิสูจน์ว่า inf S = −sup(−S) โดยที่ −S = {−x : x ∈ S}

**ระดับที่ 2 — ใช้ ε-Lemma**
4. พิสูจน์ว่า sup(A + B) = sup A + sup B โดย A + B = {a+b}
5. ยกตัวอย่างที่ sup(AB) ≠ (sup A)(sup B) · ต้องเพิ่มเงื่อนไขอะไรจึงจะจริง?
6. พิสูจน์ว่าถ้า A ⊆ B แล้ว sup A ≤ sup B

**ระดับที่ 3 — โครงสร้างชั้น 0**
7. พิสูจน์ (2) ⟹ (1) โดยตรง (MCT ⟹ LUB) โดยไม่ผ่านข้อ (3)–(5)
8. แสดงว่าสมบัติช่วงซ้อน **ล้มเหลว** ถ้าใช้ช่วงเปิด · ยกตัวอย่าง Iₙ = (0, 1/n)
   — อธิบายว่าทำไม "ปิด" จึงจำเป็น และเชื่อมกับความกระชับอย่างไร
9. ให้ f : ℚ ∩ [0,2] → ℚ, f(x) = x² · แสดงว่า f ต่อเนื่องแต่ไม่บรรลุค่าสูงสุดของ {f(x) : x² < 2}
   — ระบุให้ชัดว่าข้อไหนใน (1)–(7) พังในกรณีนี้
10. อธิบายว่าทำไมความบริบูรณ์แบบโคชีเพียงอย่างเดียวจึงยังไม่พอที่จะได้ LUB · ต้องเพิ่มอะไร และเพราะเหตุใด

**ระดับที่ 4 — เชื่อมกลับสู่แคลคูลัส**
11. ระบุตำแหน่งที่แน่นอนในบทพิสูจน์ MVT ที่ความบริบูรณ์ถูกใช้ (ย้อนกลับไปให้ถึงสัจพจน์ C)
12. ถ้าเราทำแคลคูลัสบน ℚ แทน ℝ ทฤษฎีบทใดบ้างใน Anton บทที่ 1–4 ที่ยังใช้ได้ และตัวใดพัง?
13. อธิบายว่าทำไม "ต่อเนื่องบนช่วงปิด ⟹ อินทิเกรตได้" จึงต้องผ่านความต่อเนื่องเอกรูป และทำไมความต่อเนื่องธรรมดาไม่พอ

## สรุปชั้นที่ 0 ในสามบรรทัด

1. **ℝ = สนามอันดับ + สัจพจน์หนึ่งข้อ** และสัจพจน์นั้นมีเจ็ดหน้ากากที่สมมูลกันสนิท
2. **ทุกทฤษฎีบท "มีอยู่จริง" ในแคลคูลัส คือหน้ากากใดหน้ากากหนึ่งที่ถูกแต่งตัวใหม่** — งานของนักเรียนคือถอดหน้ากากออกให้เป็น
3. **เส้นที่ยาวที่สุดในแผนที่คือ:** สัจพจน์ C → BW → ไฮเนอ–คันทอร์ → ต่อเนื่อง⟹อินทิเกรตได้ → FTC → สโตกส์

---

**ชั้นถัดไป:** ชั้นที่ 1 — ลิมิตและ ε–δ · เราจะดูว่านิยามลิมิตทำหน้าที่เป็น "ภาษา" ที่แปลสัจพจน์ C ให้กลายเป็นข้อความเกี่ยวกับฟังก์ชันได้อย่างไร และทำไมนิยามเดียวจึงใช้ได้กับลำดับ ฟังก์ชัน ℝⁿ และปริภูมิเมตริกทั่วไป
