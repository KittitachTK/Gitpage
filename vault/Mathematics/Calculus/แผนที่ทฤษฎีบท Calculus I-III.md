# แผนที่ทฤษฎีบท: Calculus I–II–III
### โครงสร้างเชิงตรรกะของแคลคูลัสทั้งหมด อ้างอิง Anton, *Calculus* 10th ed.

> **สิ่งที่ตัดออกโดยเจตนา:** สูตรอนุพันธ์ (power/product/quotient/trig/exp/log), ตารางอินทิกรัล, เทคนิคการอินทิเกรต (trig substitution, partial fractions เชิงกลไก), สูตรเรขาคณิต, การคำนวณเชิงตัวเลข
>
> **สิ่งที่เก็บไว้:** เฉพาะ *ข้อความที่ต้องพิสูจน์* และ *เส้นลูกศรที่เชื่อมมันเข้าด้วยกัน*

**สัญลักษณ์ที่ใช้ในแผนที่**

| สัญลักษณ์ | ความหมาย |
|---|---|
| `A ⟹ B` | A พิสูจน์ B / B เป็นผลพวงของ A |
| `A ⟸ B` | A ต้องใช้ B เป็นวัตถุดิบ |
| `A ≅ B` | A กับ B คือทฤษฎีบทเดียวกันในรูปทั่วไป |
| `⇢` | จุดเชื่อมออกไปยังคณิตศาสตร์ชั้นสูง (นอก Anton) |

---

## ภาพรวม: กระดูกสันหลัง 5 สาย

แคลคูลัสทั้งสามเทอมไม่ใช่ 15 บทที่ไม่เกี่ยวกัน แต่เป็น **5 สายเลือด** ที่พันกันอยู่

| สาย | ต้นน้ำ | ปลายน้ำ |
|---|---|---|
| **1. สายความมีอยู่จริง** (Existence) | สัจพจน์ความบริบูรณ์ | IVT, EVT, Rolle, MVT, ทฤษฎีบทลู่เข้าทั้งหมด |
| **2. สายเชิงเส้นเฉพาะที่** (Linearization) | นิยามอนุพันธ์ | Chain rule → Taylor → Gradient → Jacobian → Differential form |
| **3. สาย FTC** (อนุพันธ์ ↔ ปริพันธ์) | ผลพวงของ MVT | FTC → Green → Stokes → Divergence → Generalized Stokes |
| **4. สายการลู่เข้า** (Convergence) | นิยามลิมิต | ลำดับ → อนุกรม → อนุกรมกำลัง → Taylor series |
| **5. สายเรขาคณิต** (Geometry) | เวกเตอร์ | เส้นโค้ง → ความโค้ง → พื้นผิว → แมนิโฟลด์ |

**ประโยคเดียวที่สรุปแคลคูลัสทั้งหมด:**
> *"ถ้าเรารู้พฤติกรรมเฉพาะที่ของสิ่งหนึ่ง (อนุพันธ์) เราจะกู้พฤติกรรมโดยรวมของมันกลับมาได้ (ปริพันธ์) — และตัวเชื่อมทั้งหมดนี้ตั้งอยู่บนความบริบูรณ์ของ ℝ"*

# ชั้นที่ 0 — รากฐาน: ระบบจำนวนจริง

### สัจพจน์ความบริบูรณ์ (Completeness / Least Upper Bound Axiom)
> ทุกเซตย่อยของ ℝ ที่ไม่ว่างและมีขอบเขตบน มีขอบเขตบนน้อยสุด (supremum) อยู่ใน ℝ

**นี่คือสิ่งเดียวที่แยก ℝ ออกจาก ℚ** และเป็นต้นน้ำของ *ทุกทฤษฎีบทที่ขึ้นต้นว่า "มีจุด c อยู่จริงที่..."*

```
สัจพจน์ความบริบูรณ์
 ├─⟹ สมบัติอาร์คิมีดีส ⟹ 1/n → 0 ⟹ ℚ หนาแน่นใน ℝ
 ├─⟹ ทฤษฎีบทลำดับโมโนโทน (Anton 9.2)
 ├─⟹ ทฤษฎีบทช่วงซ้อน (Nested Interval) ⟹ วิธีแบ่งครึ่ง
 ├─⟹ Bolzano–Weierstrass ⟹ ความกระชับ (compactness)
 └─⟹ เกณฑ์โคชี (Cauchy criterion)
```

**⚠️ จุดสังเกตสำคัญ:** Anton *ไม่พิสูจน์* IVT และ EVT เลย (ผลักไปที่ Appendix D และบอกว่า "ยกให้วิชาชั้นสูง") เหตุผลคือทั้งสองต้องใช้สัจพจน์นี้โดยตรง ตรงนี้คือ **รูโหว่ที่ตั้งใจเว้นไว้** และเป็นประตูเข้าสู่ Real Analysis

**💡 Key Insight #1**
> ทุกทฤษฎีบทในแคลคูลัสแบ่งได้เป็น 2 ชนิดเท่านั้น — **ทฤษฎีบทคำนวณ** (บอกวิธีหาค่า) กับ **ทฤษฎีบทการมีอยู่** (บอกว่ามีคำตอบแต่ไม่บอกว่าอยู่ไหน) ชนิดหลังทั้งหมดสืบสายมาจากสัจพจน์บรรทัดเดียวข้างบนนี้

`⇢ Real Analysis, การสร้าง ℝ ด้วย Dedekind cut / Cauchy sequence, Metric space completeness`

# ชั้นที่ 1 — ลิมิต (Anton 1.1–1.4)

### นิยาม ε–δ (§1.4)
> ∀ε>0 ∃δ>0 : 0<|x−a|<δ ⟹ |f(x)−L|<ε

เครื่องมือเดียวที่ทำให้ทุกอย่างข้างบนและข้างล่างมีความหมาย ทฤษฎีบทในชั้นนี้:

| ทฤษฎีบท | ขึ้นกับ | ให้กำเนิด |
|---|---|---|
| **เอกลักษณ์ของลิมิต** | ε–δ | ทำให้เขียน "lim = L" ได้อย่างมีความหมาย |
| **กฎพีชคณิตของลิมิต** (§1.2) | ε–δ + อสมการสามเหลี่ยม | กฎอนุพันธ์ทั้งหมด, กฎปริพันธ์ทั้งหมด |
| **ทฤษฎีบทบีบ** (Squeeze, §1.6) | ε–δ | lim(sin x)/x = 1 ⟹ อนุพันธ์ตรีโกณ ⟹ อนุกรมเทย์เลอร์ของ sin |
| **ลิมิตที่อนันต์** (§1.3) | ขยาย ε–δ | เส้นกำกับ → ปริพันธ์ไม่ตรงแบบ → อนุกรมอนันต์ |

**💡 Key Insight #2 — นิยามลิมิตมีแค่แบบเดียว**
> ลิมิตของลำดับ (§9.1) = ลิมิตฟังก์ชันที่จำกัดโดเมนเป็น ℕ
> ลิมิตใน ℝⁿ (§13.2) = เปลี่ยน `|x−a|` เป็น `‖x−a‖` เท่านั้น
> ทั้งสามอย่างคือ **ประโยคเดียวกัน** ⇢ ในปริภูมิเมตริกทั่วไปเขียนว่า `d(x,a)<δ ⟹ d(f(x),L)<ε`

`⇢ Topology: ความต่อเนื่อง = ภาพผกผันของเซตเปิดเป็นเซตเปิด (นิยามที่ไม่ต้องใช้ ε–δ เลย)`

# ชั้นที่ 2 — ความต่อเนื่อง (§1.5–1.6, §3.4)

### สองทฤษฎีบทเสาหลัก

**ทฤษฎีบทค่าระหว่างกลาง (IVT, §1.5)**
> f ต่อเนื่องบน [a,b], k อยู่ระหว่าง f(a) กับ f(b) ⟹ ∃c∈[a,b] : f(c)=k

```
IVT ⟸ สัจพจน์ความบริบูรณ์ (ผ่านการแบ่งครึ่ง / sup)
IVT ⟹ ทฤษฎีบทการมีรากของสมการ
IVT ⟹ f ต่อเนื่องและหนึ่งต่อหนึ่งบนช่วง ⟹ f โมโนโทน
        ⟹ ฟังก์ชันผกผันมีอยู่จริงและต่อเนื่อง (§0.4, §6.1)
IVT ⟹ ทฤษฎีบทค่าเฉลี่ยสำหรับปริพันธ์ (§4.8)
IVT ⟹ การเปลี่ยนพารามิเตอร์ด้วยความยาวส่วนโค้ง (§12.3)
```
`⇢ IVT คือ "ความเชื่อมโยง" (connectedness) ในภาษาโทโพโลยี: ภาพต่อเนื่องของเซตเชื่อมโยงคือเซตเชื่อมโยง`

**ทฤษฎีบทค่าสูงสุด-ต่ำสุด (EVT, §3.4)**
> f ต่อเนื่องบน [a,b] (ปิดและมีขอบเขต) ⟹ f มีค่าสูงสุดสัมบูรณ์และต่ำสุดสัมบูรณ์บน [a,b]

```
EVT ⟸ Bolzano–Weierstrass ⟸ สัจพจน์ความบริบูรณ์
EVT ⟹ ทฤษฎีบทแฟร์มา ⟹ Rolle ⟹ MVT ⟹ [แทบทุกอย่างในแคลคูลัส 1]
EVT ⟹ ความต่อเนื่องเอกรูป (Heine–Cantor) ⟹ ต่อเนื่อง ⟹ อินทิเกรตได้
EVT ⟹ (เวอร์ชัน ℝⁿ, §13.8) การมีอยู่ของ extrema บนเซตปิดมีขอบเขต ⟹ Lagrange multipliers
```
`⇢ EVT คือ "ความกระชับ" (compactness): ภาพต่อเนื่องของเซตกระชับคือเซตกระชับ + ทฤษฎีบท Heine–Borel`

**💡 Key Insight #3 — สองเสาที่คู่กันเสมอ**
> IVT = **connectedness** (โดเมนไม่ขาดตอน) · EVT = **compactness** (โดเมนปิดและไม่หนีไปอนันต์)
> ทั้งวิชาแคลคูลัส เมื่อคุณเห็นสมมติฐาน "ต่อเนื่องบนช่วงปิด [a,b]" ให้อ่านว่า *"ผมกำลังจะใช้ IVT หรือ EVT"*

# ชั้นที่ 3 — อนุพันธ์ในฐานะการประมาณเชิงเส้น (§2.x)

### นิยามที่แท้จริง (§2.9 Local Linear Approximation)
สูตร `f′(a) = lim (f(a+h)−f(a))/h` เป็นเพียง *วิธีคำนวณ* — **นิยามเชิงมโนทัศน์** ที่ขยายไปได้ทุกมิติคือ:

> f หาอนุพันธ์ได้ที่ a ⟺ ∃ ค่าคงที่ m ที่ทำให้ `f(a+h) = f(a) + m·h + o(h)`

**นี่คือประโยคที่จะถูกใช้ซ้ำอีก 4 ครั้งในวิชานี้:**

| บริบท | รูปของประโยคเดียวกันนี้ | Anton |
|---|---|---|
| 1 ตัวแปร | f(a+h) = f(a) + f′(a)h + o(h) | §2.9 |
| อันดับสูง | f(a+h) = Σ f⁽ᵏ⁾(a)hᵏ/k! + Rₙ | §9.7 |
| หลายตัวแปร | f(**a**+**h**) = f(**a**) + ∇f(**a**)·**h** + o(‖**h**‖) | §13.4 |
| ℝⁿ→ℝᵐ | **f**(**a**+**h**) = **f**(**a**) + J(**a**)**h** + o(‖**h**‖) | §14.7 (Jacobian) |
| แมนิโฟลด์ | df เป็นแผนที่เชิงเส้นบนปริภูมิสัมผัส | `⇢` |

### ทฤษฎีบทในชั้นนี้
```
หาอนุพันธ์ได้ ⟹ ต่อเนื่อง            (§2.2) — ทางเดียวเท่านั้น! สวนกลับไม่จริง (|x| ที่ 0)
กฎลูกโซ่ (§2.6) ⟸ ความเป็นเชิงเส้นเฉพาะที่
   ├─⟹ การหาอนุพันธ์โดยปริยาย (§2.7) ⟹ อัตราสัมพัทธ์ (§2.8)
   ├─⟹ อนุพันธ์ของฟังก์ชันผกผัน (§6.3) ⟸ IVT (การมีอยู่ของ f⁻¹)
   ├─⟹ กฎการแทนค่า (§4.3) — เมื่ออ่านย้อนกลับผ่าน FTC
   ├─⟹ กฎลูกโซ่หลายตัวแปร (§13.5) ⟹ อนุพันธ์ระบุทิศทาง (§13.6)
   └─⟹ FTC สำหรับปริพันธ์ตามเส้น (§15.3)
```

**💡 Key Insight #4 — ทำไมกฎลูกโซ่ถึงอยู่ทุกที่**
> กฎลูกโซ่ = "การประกอบของแผนที่เชิงเส้น คือผลคูณของเมทริกซ์"
> ในมิติ 1 เมทริกซ์คือตัวเลขตัวเดียว จึงดูเหมือนแค่การคูณ — พอขึ้น ℝⁿ มันเผยตัวจริงเป็น `J(g∘f) = J(g)·J(f)`
> `⇢ นี่คือ functor ระหว่างหมวดหมู่ของแมนิโฟลด์กับหมวดหมู่ของปริภูมิเวกเตอร์`

# ชั้นที่ 4 — เครื่องยนต์กลาง: ทฤษฎีบทค่าเฉลี่ย (§3.8)

**นี่คือหัวใจของแคลคูลัสเชิงอนุพันธ์ทั้งหมด** สายการสืบทอดชัดเจนมาก:

```
                    สัจพจน์ความบริบูรณ์
                            │
                          EVT (§3.4)
                            │
              ทฤษฎีบทแฟร์มา / จุดวิกฤต (§3.2)
        [f หาอนุพันธ์ได้, มี extremum ภายใน ⟹ f′=0]
                            │
                  ทฤษฎีบทโรลล์ (§3.8)
                            │
                     MVT (§3.8)
        [∃c : f′(c) = (f(b)−f(a))/(b−a)]
                    ╱               ╲
        Cauchy MVT (ทั่วไป)      ผลพวง 6 ข้อ ↓
             ╱        ╲
   กฎโลปีตาล (§6.5)   ทฤษฎีบทเทย์เลอร์พร้อมเศษเหลือ (§9.7, §9.9)
```

### ผลพวงของ MVT — ทั้ง 6 ข้อคือทฤษฎีบทเดียวกันในเสื้อผ้าคนละชุด

| # | ผลพวง | Anton | ไปโผล่ที่ไหนต่อ |
|---|---|---|---|
| 1 | `f′≡0 บนช่วง ⟹ f คงที่` | §4.2 | **⟹ ปฏิยานุพันธ์ต่างกันแค่ค่าคงที่ ⟹ ทำให้ "+C" มีความหมาย ⟹ ทำให้ FTC ภาค 2 ใช้ได้** |
| 2 | `f′>0 ⟹ f เพิ่ม` | §3.1 | การทดสอบอนุพันธ์อันดับหนึ่ง (§3.2), ลำดับโมโนโทน (§9.2) |
| 3 | `f″>0 ⟹ f เว้าขึ้น` | §3.1 | การทดสอบอนุพันธ์อันดับสอง ⟹ เวอร์ชัน Hessian (§13.8) |
| 4 | `\|f′\|≤M ⟹ f เป็นลิปชิตซ์` | — | การลู่เข้าของวิธีนิวตัน (§3.7), ขอบเขตความคลาดเคลื่อนของออยเลอร์ (§8.3) |
| 5 | ขอบเขตเศษเหลือของเทย์เลอร์ | §9.7 | **การลู่เข้าของอนุกรมเทย์เลอร์ (§9.9)** |
| 6 | ขอบเขตความคลาดเคลื่อนเชิงตัวเลข | §7.7 | Trapezoid / Simpson |

**💡 Key Insight #5 — MVT คือสะพานเฉพาะที่ → โดยรวม**
> MVT แปลข้อมูล *ที่จุดหนึ่ง* (ค่าอนุพันธ์) ให้กลายเป็นข้อสรุป *ตลอดทั้งช่วง*
> **ทุกครั้ง** ที่คุณเห็นทฤษฎีบทที่บอกว่า "รู้ f′ แล้วสรุปเรื่อง f ได้" — นั่นคือ MVT ปลอมตัวมา
> และนี่คือเหตุผลที่ FTC เป็นไปได้: FTC ภาค 2 คือ MVT ที่ถูกบวกสะสมทีละช่วงย่อยแล้วหักล้างกันเป็นชุด (telescoping)

# ชั้นที่ 5 — ปริพันธ์และทฤษฎีบทหลักมูล (§4.x)

### ลำดับการสร้าง
```
ผลบวกรีมันน์ (§4.4)
   └─⟹ นิยามปริพันธ์จำกัดเขต (§4.5) [ลิมิตที่ไม่ขึ้นกับการแบ่งและจุดตัวอย่าง]
          └─⟸ ทฤษฎีบท: f ต่อเนื่องบน [a,b] ⟹ f อินทิเกรตได้
                 └─⟸ ความต่อเนื่องเอกรูป ⟸ EVT/ความกระชับ  ← จุดที่ชั้น 0 กลับมาทำงาน
```

### ทฤษฎีบทค่าเฉลี่ยสำหรับปริพันธ์ (§4.8)
> f ต่อเนื่องบน [a,b] ⟹ ∃c : ∫ₐᵇf = f(c)(b−a)

**⚠️ อย่าสับสน:** ตัวนี้ **ไม่ได้** มาจาก MVT ของอนุพันธ์ แต่มาจาก **EVT + IVT** โดยตรง (ค่าเฉลี่ยของ f ต้องอยู่ระหว่าง min กับ max จึงถูกแตะถึงโดย IVT) — เป็นหลักฐานว่าชั้น 2 ยังทำงานเงียบ ๆ อยู่

### ทฤษฎีบทหลักมูลของแคลคูลัส (§4.6)

**ภาค 1 (อนุพันธ์ของปริพันธ์):** `F(x)=∫ₐˣ f(t)dt ⟹ F′(x)=f(x)`
```
⟸ ทฤษฎีบทค่าเฉลี่ยสำหรับปริพันธ์ ⟸ EVT + IVT
⟹ ทุกฟังก์ชันต่อเนื่องมีปฏิยานุพันธ์ (ทฤษฎีบทการมีอยู่!)
⟹ นิยาม ln x = ∫₁ˣ dt/t ได้อย่างเข้มงวด (§6.6)  ← Anton สร้าง log ใหม่ทั้งหมดจากตรงนี้
⟹ ฟังก์ชันข้อผิดพลาด, ฟังก์ชันพิเศษที่ไม่มีสูตรปิด
```

**ภาค 2 (การประเมินค่า):** `∫ₐᵇ f = F(b)−F(a)`
```
⟸ ภาค 1 + ผลพวงข้อ 1 ของ MVT (เอกลักษณ์ของปฏิยานุพันธ์)
   หรือพิสูจน์ตรงจาก MVT + ผลบวกหักล้าง ← เส้นทางนี้คือสายที่จะกลายเป็น Stokes
```

**💡 Key Insight #6 — FTC พูดว่าอะไรกันแน่**
> ถอดออกมาเป็นภาษาคน: **"ผลรวมของอัตราการเปลี่ยนแปลงตลอดภายในก้อนหนึ่ง = ผลต่างสุทธิที่วัดได้ตรงขอบของก้อนนั้น"**
> ประโยคนี้ **ไม่มีคำว่ามิติหนึ่ง** อยู่เลย — และนั่นคือเหตุผลที่มันจะกลับมาอีก 4 ครั้งในบทที่ 15 ในชื่อ Green, Stokes, Divergence
> เขียนเป็นสัญลักษณ์: `∫_[a,b] F′ = ∫_{a,b} F` ⟹ `∫_M dω = ∫_∂M ω`

```
∇· (div)   : สนามเวกเตอร์ → ฟังก์ชัน      [2-form → 3-form]

⇢ ทั้งสามคือ **ตัวดำเนินการ d ตัวเดียวกัน** ที่กระทำบนรูปเชิงอนุพันธ์ต่างอันดับ
   และ curl∘grad = 0, div∘curl = 0 คือ **d² = 0** ⟸ ทฤษฎีบทแคลโรต์ (§13.3)
```

### สายโซ่ FTC ที่สมบูรณ์

| ทฤษฎีบท | Anton | ก้อน M | ขอบ ∂M | ข้อความ |
|---|---|---|---|---|
| **FTC** | §4.6 | ช่วง [a,b] | จุดสองจุด | ∫ₐᵇ F′dx = F(b)−F(a) |
| **FTC สำหรับปริพันธ์ตามเส้น** | §15.3 | เส้นโค้ง C | จุดปลายสองจุด | ∫_C ∇f·dr = f(B)−f(A) |
| **ทฤษฎีบทกรีน** | §15.4 | บริเวณในระนาบ R | เส้นโค้งปิด ∂R | ∮_∂R F·dr = ∬_R (∂Q/∂x−∂P/∂y)dA |
| **ทฤษฎีบทสโตกส์** | §15.8 | ผิว S ในสเปซ | เส้นโค้งขอบ ∂S | ∮_∂S F·dr = ∬_S (∇×F)·n dS |
| **ทฤษฎีบทไดเวอร์เจนซ์** | §15.7 | ปริมาตร G | ผิวปิด ∂G | ∯_∂G F·n dS = ∭_G (∇·F)dV |

### สนามอนุรักษ์: จุดที่โทโพโลยีเข้ามาบังคับการวิเคราะห์ (§15.3)
```
F = ∇f  ⟺  ปริพันธ์ไม่ขึ้นกับเส้นทาง  ⟺  ∮ รอบวงปิดใด ๆ = 0
                      ⇓ (ทางเดียวเสมอ)
                  ∇×F = 0
                      ⇑ (จริงเฉพาะเมื่อโดเมน **เชื่อมโยงเชิงเดียว**!)
```
**ตัวอย่างค้าน:** F = (−y, x)/(x²+y²) บน ℝ²∖{0} มี curl = 0 แต่ไม่อนุรักษ์ — เพราะมีรูตรงกลาง
`⇢ นี่คือจุดกำเนิดของ de Rham cohomology: H¹ วัด "จำนวนรู" ของโดเมน` — และเป็นครั้งแรกที่ *รูปร่างของโดเมน* เปลี่ยนคำตอบของปัญหาแคลคูลัส

**💡 Key Insight #9 — ทฤษฎีบทเดียว (Generalized Stokes)**
> $$\int_M d\omega = \int_{\partial M} \omega$$
> - M = ช่วง → **FTC**
> - M = บริเวณในระนาบ → **กรีน**
> - M = ผิว → **สโตกส์**
> - M = ก้อนปริมาตร → **ไดเวอร์เจนซ์**
>
> ทั้งหมดคือประโยคเดียวกัน: **"อนุพันธ์บนก้อน = ตัวมันเองบนขอบ"**
> และคู่แฝดของมันคือ `∂(∂M) = ∅` (ขอบของขอบว่างเปล่า) ซึ่งเป็นภาพสะท้อนเชิงเรขาคณิตของ `d² = 0`
> `⇢ ความคู่กันนี้ (∂ กับ d) คือหัวใจของ Algebraic Topology`
