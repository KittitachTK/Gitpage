# Linear Transformations

A map $T: V \to W$ is **linear** if $T(\alpha u + \beta v) = \alpha T u + \beta T v$.

> [!theorem] Rank–nullity
> If $V$ is finite-dimensional, $\dim V = \operatorname{rank} T + \operatorname{nullity} T$.

> [!exercise]
> Show that the kernel of a linear map is a subspace.

| Concept | Symbol |
| --- | --- |
| Kernel | $\ker T$ |
| Image | $\operatorname{im} T$ |
