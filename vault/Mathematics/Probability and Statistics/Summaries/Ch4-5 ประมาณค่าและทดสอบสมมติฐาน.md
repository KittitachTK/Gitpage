# ส่วนที่ 0 : ภาพรวม — เชื่อม CH4 กับ CH5 ให้เป็นเรื่องเดียวกัน

## 0.1 แผนที่ความคิด

```
                        สถิติเชิงอนุมาน (Inferential Statistics)
                                      │
              ┌───────────────────────┴───────────────────────┐
              │                                               │
      การประมาณค่า (CH4)                          การทดสอบสมมติฐาน (CH5)
              │                                               │
      ┌───────┴───────┐                          "ค่าที่อ้างนี้ น่าเชื่อไหม?"
      │               │                                       │
 แบบจุด (Point)  แบบช่วง (Interval)              ตั้ง H₀/H₁ → คำนวณสถิติ → p-value → ตัดสินใจ
 "ค่าเดียว"      "ช่วง L ถึง U"
```

**พารามิเตอร์ที่เรียนทั้งหมดมี 5 ตัว** และทั้ง CH4 กับ CH5 ใช้ **5 ตัวเดียวกันเป๊ะ**

| # | พารามิเตอร์ | ความหมาย | CH4 (หา CI) | CH5 (ทดสอบ) |
|---|---|---|---|---|
| 1 | μ | ค่าเฉลี่ย 1 ประชากร | ✔ | ✔ |
| 2 | μ₁ − μ₂ | ผลต่างค่าเฉลี่ย 2 ประชากร (ตัวอย่างอิสระ) | ✔ | ✔ |
| 3 | μ_D | ผลต่างค่าเฉลี่ย 2 ประชากร (ตัวอย่างสัมพันธ์กัน / จับคู่) | ✔ | ✔ |
| 4 | p | สัดส่วน 1 ประชากร | ✔ | ✔ |
| 5 | p₁ − p₂ | ผลต่างสัดส่วน 2 ประชากร | ✔ | ✔ |

## 0.2 🔑 กุญแจสำคัญที่สุด : สูตรทั้งหมดมาจาก "แม่แบบ" เดียวกัน

ทั้ง 2 บท ใช้ปริมาณกลางตัวเดียวกัน คือ **ความคลาดเคลื่อนมาตรฐาน (Standard Error, SE)**
ซึ่งก็คือ "ส่วนเบี่ยงเบนมาตรฐานของตัวประมาณ"

| | แม่แบบ | ความหมาย |
|---|---|---|
| **CH4** | `ค่าประมาณแบบจุด ± (ค่าวิกฤต) × SE` | ตีกรอบว่าพารามิเตอร์จริงน่าจะอยู่ที่ไหน |
| **CH5** | `สถิติทดสอบ = (ค่าประมาณแบบจุด − ค่าตาม H₀) / SE` | นับว่าข้อมูล "ห่าง" จากค่าที่อ้างกี่หน่วย SE |

> **เพราะฉะนั้น ถ้าจำ SE ของแต่ละพารามิเตอร์ได้ ก็เขียนสูตรได้ทั้ง 2 บททันที**
> ไม่ต้องท่องสูตรแยกกัน 20 สูตร ท่องแค่ **SE 5 แบบ + ตัวคูณ (z หรือ t)**

### ตาราง SE ที่ต้องจำ (หัวใจของทั้ง 2 บท)

| พารามิเตอร์ | ค่าประมาณแบบจุด | SE (เมื่อทราบ σ) | SE (เมื่อไม่ทราบ σ) |
|---|---|---|---|
| μ | X̄ | σ/√n | S/√n |
| μ₁−μ₂ | X̄₁ − X̄₂ | √(σ₁²/n₁ + σ₂²/n₂) | √(S₁²/n₁ + S₂²/n₂) หรือ √(S²_p(1/n₁+1/n₂)) |
| μ_D | D̄ | — | S_D/√n |
| p | p̂ = x/n | — | √(p̂q̂/n) *(ตอนหา CI)* / √(p₀q₀/n) *(ตอนทดสอบ)* |
| p₁−p₂ | p̂₁ − p̂₂ | — | √(p̂₁q̂₁/n₁ + p̂₂q̂₂/n₂) หรือ √(p̄q̄(1/n₁+1/n₂)) |

## 0.3 ความสัมพันธ์แบบ "คู่แฝด" ระหว่าง CI กับ การทดสอบสองทาง

> **ช่วงความเชื่อมั่น (1−α)100% ไม่คลุมค่าตาม H₀  ⇔  ปฏิเสธ H₀ ที่ระดับนัยสำคัญ α (แบบสองทาง)**

ตัวอย่างจากเอกสาร (กรณีศึกษาโควิด-19) :
- 95% CI ของ μ_ชาย − μ_หญิง = (0.894, 5.842) → **ไม่คลุม 0**
- ทดสอบ H₀: μ_ชาย − μ_หญิง = 0 → p-value = 0.008 < 0.05 → **ปฏิเสธ H₀**
- ✅ สองวิธีให้ข้อสรุปตรงกันเสมอ

**ประโยชน์:** ใช้เช็กคำตอบตัวเองในห้องสอบได้ ถ้าคำนวณ CI แล้วไม่คลุม 0 แต่สรุปว่า "ยอมรับ H₀" แสดงว่าคำนวณผิดที่ไหนสักแห่ง

# ส่วนที่ 1 : CH4 การประมาณค่า (Estimation)

## 1.1 ศัพท์พื้นฐาน 4 คำที่มักสับสน

จากตัวอย่างในเอกสาร : *นักวิจัยต้องการศึกษาค่าใช้จ่ายเฉลี่ยต่อเดือนของนักศึกษา มข. ซึ่งมีทั้งหมด 40,000 คน แต่เก็บจริงได้เพียง 500 คน ได้ค่าเฉลี่ย 5,000 บาท*

| ศัพท์ | สัญลักษณ์ | ในตัวอย่างนี้คือ |
|---|---|---|
| **พารามิเตอร์** (Parameter) | μ | ค่าใช้จ่ายเฉลี่ยของ นศ. ทั้ง 40,000 คน (ไม่รู้ค่า) |
| **ตัวสถิติ** (Statistic) | X̄ | ค่าใช้จ่ายเฉลี่ยของตัวอย่างที่สุ่มมา |
| **ตัวประมาณ** (Estimator) | X̄ | "สูตร/ตัวแปรสุ่ม" ที่ใช้ประมาณ μ |
| **ค่าประมาณ** (Estimate) | x̄ = 5,000 | "ตัวเลข" ที่คำนวณได้จริง |

> 💡 **จำง่าย:** Estimator = *เครื่องมือ* , Estimate = *ผลลัพธ์ที่ออกมาเป็นตัวเลข*

## 1.2 คุณสมบัติของตัวประมาณที่ดี (3 ข้อ)

**1) ไม่เอนเอียง (Unbiased)**
> ถ้า E(θ̂) = θ เรียก θ̂ ว่าเป็นตัวประมาณที่ไม่เอนเอียงของ θ

*ความหมาย:* ถ้าสุ่มซ้ำ ๆ หลายรอบ ค่าเฉลี่ยของค่าประมาณจะเท่ากับค่าจริงพอดี (ไม่ยิงเบี่ยงซ้าย/ขวาอย่างเป็นระบบ)

**2) ไม่เอนเอียง และมีความแปรปรวนต่ำสุด (Minimum variance)**
> ให้ X̄ และ Me ต่างก็เป็นตัวประมาณที่ไม่เอนเอียงของ μ
> ถ้าพิสูจน์ได้ว่า Var(X̄) < Var(Me) แสดงว่า **X̄ มีประสิทธิภาพมากกว่า Me**

*ความหมาย:* ยิงตรงเป้าเหมือนกัน แต่ตัวไหนกระจายแคบกว่า ตัวนั้นดีกว่า

**3) ความแนบนัย / ความคงเส้นคงวา (Consistency)**
> เช่น X̄ → μ เมื่อ n → N

*ความหมาย:* ยิ่งเก็บตัวอย่างมาก ค่าประมาณยิ่งเข้าใกล้ค่าจริง

## 1.3 การประมาณค่าแบบจุด (Point Estimation)

> ประมาณพารามิเตอร์ด้วย **ค่าเดียว** ไม่มีการบอกความคลาดเคลื่อน

| พารามิเตอร์ | ตัวประมาณแบบจุด | สูตร |
|---|---|---|
| μ | X̄ | X̄ = Σᵢ₌₁ⁿ Xᵢ / n |
| μ₁ − μ₂ | X̄₁ − X̄₂ | (ΣX₁ᵢ/n₁) − (ΣX₂ᵢ/n₂) |
| μ_D | D̄ | D̄ = ΣDᵢ/n , Dᵢ = X_i1 − X_i2 |
| p | p̂ | p̂ = x/n = (จำนวนตัวอย่างที่สนใจ)/(จำนวนตัวอย่างทั้งหมด) |
| p₁ − p₂ | p̂₁ − p̂₂ | (x₁/n₁) − (x₂/n₂) |
| σ² | S² | S² = Σ(Xᵢ − X̄)²/(n−1) = [ΣXᵢ² − (ΣXᵢ)²/n] / (n−1) |

> ⚠️ **สูตร S² แบบ "สูตรลัด"** `S² = [ΣX² − (ΣX)²/n]/(n−1)` คือสูตรที่ใช้จริงในเอกสารเวลาคำนวณด้วยมือ เพราะต้องการแค่ **ΣX และ ΣX²** ไม่ต้องหาผลต่างทีละตัว — ในห้องสอบใช้ตัวนี้เร็วกว่ามาก

**ข้อจำกัดของการประมาณแบบจุด:** โอกาสที่ค่าประมาณจะ *เท่ากับ* พารามิเตอร์จริงเป๊ะ ๆ แทบเป็นศูนย์ และไม่บอกว่าคลาดเคลื่อนได้แค่ไหน → จึงต้องมี **การประมาณแบบช่วง**

## 1.4 การประมาณค่าแบบช่วง (Interval Estimation)

หาค่า L (Lower) และ U (Upper) ที่ทำให้

> **P(L < θ < U) = 1 − α**

เรียกช่วง (L, U) ว่า **ช่วงความเชื่อมั่น (Confidence Interval : CI) (1−α)100% ของ θ**

### 🔴 การตีความที่ถูกต้อง (ออกสอบบ่อย!)

| ❌ ผิด | ✅ ถูก |
|---|---|
| "μ มีโอกาส 95% ที่จะอยู่ในช่วงนี้" | "ถ้าสุ่มตัวอย่างและสร้าง CI แบบนี้ซ้ำ 100 ครั้ง จะมีประมาณ 95 ช่วงที่คลุมค่า μ จริง" |

เพราะ μ เป็น **ค่าคงที่** ไม่ใช่ตัวแปรสุ่ม — สิ่งที่สุ่มคือ *ช่วง* ต่างหาก

### ค่าวิกฤตที่ใช้บ่อย (ต้องจำ)

| ระดับความเชื่อมั่น | α    | α/2   | z_(α/2) *(สองทาง)* | z_α *(ทางเดียว)* |
| ------------------ | ---- | ----- | ------------------ | ---------------- |
| 90%                | 0.10 | 0.05  | **1.645**          | 1.28             |
| 95%                | 0.05 | 0.025 | **1.96**           | **1.645**        |
| 98%                | 0.02 | 0.01  | 2.33               | 2.05             |
| 99%                | 0.01 | 0.005 | **2.576 (2.58)**   | **2.33**         |

## 1.5 ⭐ กรณีที่ 1 : ช่วงความเชื่อมั่นของ μ (1 ประชากร)

### แบ่งเป็น 3 กรณี ตาม "รู้ σ² ไหม" และ "n ใหญ่ไหม"

**🟡 กรณีที่ 1 — ทราบค่า σ² (n เท่าใดก็ได้)**

```
X̄ − z_(α/2)·(σ/√n)  <  μ  <  X̄ + z_(α/2)·(σ/√n)
```

**🟠 กรณีที่ 2 — ไม่ทราบ σ² และ n < 30**

```
X̄ − t_(α/2, n−1)·(S/√n)  <  μ  <  X̄ + t_(α/2, n−1)·(S/√n)
```

**🟣 กรณีที่ 3 — ไม่ทราบ σ² และ n ≥ 30**

```
X̄ − z_(α/2)·(S/√n)  <  μ  <  X̄ + z_(α/2)·(S/√n)
```

เมื่อ **S = √[ (1/(n−1)) Σᵢ₌₁ⁿ (Xᵢ − X̄)² ]**

### 🧠 แนวคิด : ทำไมต้องแบ่ง 3 กรณี?

| | เหตุผล |
|---|---|
| **กรณี 1 ใช้ z** | (X̄−μ)/(σ/√n) ~ N(0,1) เป๊ะ ๆ เพราะ σ เป็นค่าคงที่ที่รู้แน่นอน ไม่มีความไม่แน่นอนเพิ่ม |
| **กรณี 2 ใช้ t** | เอา S (ค่าประมาณ) ไปแทน σ ⇒ เกิดความไม่แน่นอน **2 ชั้น** (จาก X̄ และจาก S) การแจกแจงจึงหางอ้วนกว่าปกติ = **t มี df = n−1** |
| **กรณี 3 ใช้ z ได้อีก** | เมื่อ n ≥ 30 การแจกแจง t ลู่เข้าสู่ Z (ที่ df=29, t = 2.045 ≈ z = 1.96) ⇒ อนุโลมใช้ z แทน t เพื่อความสะดวก |

> 📌 **ผังตัดสินใจแบบเร็ว**
> ```
> รู้ σ² ?  ── ใช่ ──→ ใช้ z + σ        (ไม่สนใจ n)
>    │
>   ไม่
>    │
>    └──→ n < 30 ?  ── ใช่ ──→ ใช้ t(df = n−1) + S
>                  ── ไม่ ──→ ใช้ z + S
> ```

## 1.6 ⭐ กรณีที่ 2 : ช่วงความเชื่อมั่นของ μ₁ − μ₂ (ตัวอย่างอิสระกัน)

**🟡 กรณีที่ 1 — ทราบ σ₁² และ σ₂²**

จาก X̄₁ − X̄₂ ~ N( μ₁−μ₂ , σ₁²/n₁ + σ₂²/n₂ ) จะได้

```
Z = [(X̄₁ − X̄₂) − (μ₁ − μ₂)] / √(σ₁²/n₁ + σ₂²/n₂)  ~ N(0,1)
```

ดังนั้น CI (1−α)100% ของ μ₁ − μ₂ คือ

```
(X̄₁ − X̄₂) ± z_(α/2)·√( σ₁²/n₁ + σ₂²/n₂ )
```

**🟠 กรณีที่ 2 — ไม่ทราบ σ₁², σ₂² ; n₁ < 30, n₂ < 30 ; แต่ทราบว่า σ₁² = σ₂²**

```
T = [(X̄₁ − X̄₂) − (μ₁ − μ₂)] / √( S²_p (1/n₁ + 1/n₂) )     มี df: ν = n₁ + n₂ − 2

โดย   S²_p = [ (n₁−1)S₁² + (n₂−1)S₂² ] / (n₁ + n₂ − 2)
```

CI (1−α)100% ของ μ₁ − μ₂ คือ

```
(X̄₁ − X̄₂) ± t_(α/2, n₁+n₂−2)·√( S²_p (1/n₁ + 1/n₂) )
```

**🟣 กรณีที่ 3 — ไม่ทราบ σ₁², σ₂² ; n₁ < 30, n₂ < 30 ; แต่ทราบว่า σ₁² ≠ σ₂²**

```
T = [(X̄₁ − X̄₂) − (μ₁ − μ₂)] / √( S₁²/n₁ + S₂²/n₂ )

องศาเสรี (Welch–Satterthwaite) :

        ( S₁²/n₁ + S₂²/n₂ )²
ν = ─────────────────────────────────      ← มีเศษให้ "ปัดทิ้ง"
     (S₁²/n₁)²/(n₁−1) + (S₂²/n₂)²/(n₂−1)
```

CI (1−α)100% ของ μ₁ − μ₂ คือ

```
(X̄₁ − X̄₂) ± t_(α/2, ν)·√( S₁²/n₁ + S₂²/n₂ )
```

### 🧠 แนวคิด : S²_p คืออะไร ทำไมต้องรวมความแปรปรวน?

- ถ้าเชื่อว่าประชากรทั้งสองมีความแปรปรวน **เท่ากัน** (σ₁² = σ₂²) แปลว่า S₁² และ S₂² ต่างก็เป็นตัวประมาณของ *ค่าเดียวกัน*
- แทนที่จะใช้แค่ตัวใดตัวหนึ่ง เรา **"รวมพลัง" (pool)** ทั้งสองเข้าด้วยกัน โดยถ่วงน้ำหนักด้วย df ของแต่ละกลุ่ม (n₁−1 และ n₂−1)
- ผลคือได้ตัวประมาณที่แม่นยำกว่า และได้ df รวมมากขึ้น (n₁+n₂−2) → t แคบลง → CI แคบลง = **ได้เปรียบ**
- แต่ถ้า σ₁² ≠ σ₂² จริง แล้วดันไป pool → คำตอบผิดเพี้ยน จึงต้องเช็กด้วย **Levene's Test** ก่อนเสมอ

> 📌 **ในทางปฏิบัติ (SPSS)** ให้ดู Levene's Test ก่อน :
> - Sig. > 0.05 → ยอมรับว่าความแปรปรวนเท่ากัน → อ่านบรรทัด **"Equal variances assumed"** (กรณี 2)
> - Sig. ≤ 0.05 → ความแปรปรวนต่างกัน → อ่านบรรทัด **"Equal variances not assumed"** (กรณี 3)

## 1.7 ⭐ กรณีที่ 3 : ช่วงความเชื่อมั่นของ μ_D (ตัวอย่างสัมพันธ์กัน / จับคู่)

### นิยาม

ให้ **Dᵢ = X_i1 − X_i2** ; i = 1, 2, …, n
เป็นผลต่างของตัวอย่างสุ่มจากประชากรที่มีการแจกแจงปกติ ที่มีค่าเฉลี่ย μ_D และความแปรปรวน σ²_D
โดย **μ_D = μ₁ − μ₂**

### 🔴 การตีความเครื่องหมายของ D₀ (ออกสอบแน่นอน)

| ค่า | ความหมาย |
|---|---|
| D₀ = 0 | ก่อนและหลังทดลอง **ไม่แตกต่างกัน** |
| D₀ > 0 | **ก่อน**ทดลองให้ค่าเฉลี่ย **สูงกว่า** หลังทดลอง |
| D₀ < 0 | **ก่อน**ทดลองให้ค่าเฉลี่ย **ต่ำกว่า** หลังทดลอง |

*(ยึดตามนิยาม D = ก่อน − หลัง)*

### สูตร

```
D̄ = Σᵢ₌₁ⁿ Dᵢ / n

S²_D = [ Σᵢ₌₁ⁿ Dᵢ² − (Σᵢ₌₁ⁿ Dᵢ)²/n ] / (n − 1)
```

**🟠 กรณีที่ 1 — n < 30**

```
T = (D̄ − μ_D)/(S_D/√n)   มี df: ν = n − 1

CI :   D̄ − t_(α/2, n−1)·(S_D/√n)  <  μ_D  <  D̄ + t_(α/2, n−1)·(S_D/√n)
```

**🟣 กรณีที่ 2 — n ≥ 30**

```
Z = (D̄ − μ_D)/(S_D/√n) ~ N(0,1)

CI :   D̄ − z_(α/2)·(S_D/√n)  <  μ_D  <  D̄ + z_(α/2)·(S_D/√n)
```

### 🧠 แนวคิด : ทำไมจับคู่แล้วเหลือแค่ "ตัวแปรเดียว"?

- โจทย์ 2 กลุ่ม แต่พอจับคู่ (คนเดียวกัน วัดก่อน–หลัง) แล้ว **หาผลต่างทีละคู่** ปัญหา 2 ตัวอย่าง จะยุบเหลือ **ปัญหา 1 ตัวอย่าง** ที่ทำกับตัวแปร D
- ⇒ สูตรทั้งหมดจึงหน้าตาเหมือนหัวข้อ 1.5 เป๊ะ ๆ แค่เปลี่ยน X̄→D̄ , S→S_D , μ→μ_D
- **ข้อดี:** ตัดความแปรปรวนระหว่างบุคคลทิ้งไป (คนเครียดมากอยู่แล้วก็เทียบกับตัวเอง) ⇒ SE เล็กลง ⇒ **มีอำนาจการทดสอบสูงกว่า** การใช้ตัวอย่างอิสระ

> ⚠️ **จุดตัดสินสำคัญ : "อิสระ" หรือ "สัมพันธ์"?**
> - คนละคน / คนละกลุ่ม / n₁ ไม่จำเป็นต้องเท่า n₂ → **อิสระ** (หัวข้อ 1.6)
> - คนเดียวกันวัด 2 ครั้ง / จับคู่กันมา (ฝาแฝด, ก่อน–หลัง, ซ้าย–ขวา) / **n₁ = n₂ เสมอ** → **สัมพันธ์** (หัวข้อ 1.7)

---

## 1.8 ⭐ กรณีที่ 4 : ช่วงความเชื่อมั่นของ p (สัดส่วน 1 ประชากร)

**การประมาณแบบจุด**

```
p̂ = x/n = (จำนวนตัวอย่างที่สนใจ)/(จำนวนตัวอย่างทั้งหมด)
```

**การประมาณแบบช่วง**

```
p̂ − z_(α/2)·√(p̂q̂/n)  <  p  <  p̂ + z_(α/2)·√(p̂q̂/n)      เมื่อ q̂ = 1 − p̂
```

### 🧠 แนวคิด

- ตัวแปรที่สนใจเป็น **ข้อมูลเชิงกลุ่ม 2 ค่า** (เป็น/ไม่เป็น, ใช่/ไม่ใช่) ⇒ X ~ Binomial(n, p)
- เมื่อ n ใหญ่พอ ทฤษฎีบทลิมิตกลางทำให้ p̂ ≈ Normal( p , pq/n ) ⇒ ใช้ **z เสมอ ไม่ใช้ t**
- ในสูตร CI ใช้ **p̂q̂** (ค่าจากตัวอย่าง) เพราะไม่รู้ p จริง

---

## 1.9 ⭐ กรณีที่ 5 : ช่วงความเชื่อมั่นของ p₁ − p₂

**การประมาณแบบจุด**

```
p̂₁ − p̂₂ = x₁/n₁ − x₂/n₂
```

**การประมาณแบบช่วง**

```
(p̂₁ − p̂₂) − z_(α/2)·√( p̂₁q̂₁/n₁ + p̂₂q̂₂/n₂ )  <  p₁ − p₂  <  (p̂₁ − p̂₂) + z_(α/2)·√( p̂₁q̂₁/n₁ + p̂₂q̂₂/n₂ )
```

### 🧠 แนวคิด
- ความแปรปรวนของ **ผลต่าง** ของตัวแปรสุ่มที่เป็นอิสระกัน = **ผลบวก** ของความแปรปรวน
  → Var(p̂₁ − p̂₂) = p₁q₁/n₁ + p₂q₂/n₂ (บวก ไม่ใช่ลบ! ผิดกันบ่อยมาก)

# ส่วนที่ 2 : CH5 การทดสอบสมมติฐาน (Hypothesis Testing)

## 2.1 สมมติฐานคืออะไร ทำไมต้องทดสอบ?

> **สมมติฐาน** คือ ข้อสมมติเกี่ยวกับค่าพารามิเตอร์ ที่ตั้งขึ้นโดยอาศัยข้อมูลที่มี หรือคาดการณ์สิ่งที่จะเกิดขึ้น ซึ่งข้อสมมติดังกล่าวจะเป็นจริงหรือไม่ก็ได้

> **การทดสอบสมมติฐาน** คือ การทดสอบเพื่อให้ได้ข้อสรุป สำหรับตัดสินใจที่จะ *ยอมรับ* หรือ *ปฏิเสธ* สมมติฐานที่ตั้งขึ้น โดยอาศัย **ตัวสถิติ** เป็นเกณฑ์ในการตัดสินใจ

---

## 2.2 ⭐ 5 ขั้นตอนมาตรฐาน (ใช้เหมือนกันทุกโจทย์ ทุกพารามิเตอร์)

```
ขั้นที่ 1  กำหนดสมมติฐาน (H₀ , H₁)
ขั้นที่ 2  กำหนดระดับนัยสำคัญ (α)
ขั้นที่ 3  พิจารณาเลือกตัวสถิติทดสอบ + เกณฑ์การตัดสินใจ
ขั้นที่ 4  คำนวณค่าสถิติ และหาค่า p-value
ขั้นที่ 5  ทำการตัดสินใจ และสรุปผลการทดสอบ
```

> 🎯 **เทคนิคทำข้อสอบ:** เขียนหัวข้อ 1–5 ลงกระดาษก่อนเลยทุกข้อ แล้วค่อยเติมเนื้อ จะได้คะแนนขั้นตอนเต็มแม้คำนวณพลาด

---

### ขั้นที่ 1 : กำหนดสมมติฐาน

| | ชื่อ | สัญลักษณ์ | นิยาม |
|---|---|---|---|
| 1 | สมมติฐานหลัก / สมมติฐานว่าง (Null hypothesis) | **H₀** | สมมติฐานที่ต้องการทดสอบว่าเป็นจริงหรือไม่ |
| 2 | สมมติฐานรอง / สมมติฐานแย้ง (Alternative hypothesis) | **H₁** | สมมติฐานที่แย้งกับสมมติฐานหลัก |

**ตั้งได้ 3 ลักษณะ**

| | รูปแบบ | ชนิด | บริเวณปฏิเสธ H₀ |
|---|---|---|---|
| แบบที่ 1 | H₀: θ = θ₀ , H₁: θ **>** θ₀ | ทางเดียว (One-tailed) | หางขวา |
| แบบที่ 2 | H₀: θ = θ₀ , H₁: θ **<** θ₀ | ทางเดียว (One-tailed) | หางซ้าย |
| แบบที่ 3 | H₀: θ = θ₀ , H₁: θ **≠** θ₀ | สองทาง (Two-tailed) | หางซ้าย **และ** หางขวา (ข้างละ α/2) |

### 🧠 แนวคิด : จะรู้ได้อย่างไรว่าต้องตั้งแบบไหน?

**อ่านคำถามหลักของโจทย์ แล้วเอา "สิ่งที่อยากพิสูจน์" ไปไว้ที่ H₁ เสมอ**

| คำในโจทย์ | H₁ |
|---|---|
| "แตกต่างกันหรือไม่" / "ต่างไปจาก…หรือไม่" | ≠ (สองทาง) |
| "มากกว่า" / "สูงกว่า" / "เกิน" / "ดีขึ้น" | > (ทางเดียว ขวา) |
| "น้อยกว่า" / "ต่ำกว่า" / "ลดลง" / "มีประสิทธิภาพในการลด" | < (ทางเดียว ซ้าย) |

> ⚠️ **H₀ ต้องมีเครื่องหมาย = เสมอ** (เพราะต้องมีค่าเดียวไว้คำนวณการแจกแจง) และ **ห้ามใส่ตัวสถิติ (X̄, p̂) ลงในสมมติฐาน** — ใส่ได้เฉพาะพารามิเตอร์ (μ, p)

---

### 🔴 ประเภทของความผิดพลาด (Type I / Type II Error) — ออกสอบทุกปี

เนื่องจากการตัดสินใจขึ้นอยู่กับข้อมูลจากตัวอย่างสุ่ม ซึ่งมีความไม่แน่นอน จึงมีโอกาสผิดพลาดได้

| การตัดสินใจ \ สถานการณ์จริง | **H₀ เป็นจริง** | **H₀ ไม่เป็นจริง** |
|---|---|---|
| **ปฏิเสธ H₀** | ❌ ความผิดพลาดแบบที่ 1 (**α**) | ✅ ตัดสินใจถูกต้อง (1−β) = อำนาจการทดสอบ |
| **ยอมรับ H₀** | ✅ ตัดสินใจถูกต้อง (1−α) | ❌ ความผิดพลาดแบบที่ 2 (**β**) |

**ความผิดพลาดแบบที่ 1 (Type I Error) : α**
- คือ การ **ปฏิเสธ H₀ ทั้ง ๆ ที่จริง ๆ แล้ว H₀ เป็นจริง**
- เปรียบเสมือน *"ตัดสินว่าผิด ทั้งที่คนนั้นบริสุทธิ์"*
- ตัวอย่าง: H₀ = "ยานี้ไม่ช่วยรักษาโรค" แต่เราปฏิเสธ H₀ แล้วบอกว่ายาช่วยได้ ทั้งที่จริงไม่ช่วย → **การรักษาไม่เกิดประโยชน์ที่แท้จริง**

**ความผิดพลาดแบบที่ 2 (Type II Error) : β**
- คือ การ **ยอมรับ (ไม่ปฏิเสธ) H₀ ทั้ง ๆ ที่จริง ๆ แล้ว H₀ เป็นเท็จ**
- เปรียบเสมือน *"ปล่อยให้คนผิดหลุดพ้นไป"*
- ตัวอย่าง: H₀ = "ยานี้ไม่ช่วยรักษาโรค" ในความเป็นจริงยาช่วยได้ แต่ผลทดสอบทำให้ยอมรับ H₀ → **พลาดโอกาสใช้ยาที่ดี**

**ความสำคัญขึ้นอยู่กับบริบทของปัญหา**
- เรื่อง **ความปลอดภัยของชีวิต** เช่น การอนุมัติวัคซีน → **Type I Error ร้ายแรงกว่า** เพราะอาจอนุมัติสิ่งที่อันตราย
- เรื่อง **การวินิจฉัยโรค** เช่น ตรวจหาโรคร้ายแรง → **Type II Error ร้ายแรงกว่า** เพราะพลาดโอกาสรักษา

---

### ขั้นที่ 2 : กำหนดระดับนัยสำคัญ (α)

> **α** คือ ความคลาดเคลื่อนชนิดที่ 1 หรือ **ความน่าจะเป็นในการตัดสินใจที่จะปฏิเสธ H₀ เมื่อ H₀ เป็นจริง**
> โดยทั่วไปนิยมกำหนดที่ **α = 0.05**

---

### ขั้นที่ 3 : เลือกตัวสถิติทดสอบ + เกณฑ์การตัดสินใจ

พิจารณาให้สอดคล้องกับ
1) **การตั้งสมมติฐาน** (ในขั้นที่ 1) → ทางเดียวหรือสองทาง
2) **ทำการทดสอบข้อตกลงเบื้องต้น (Assumption) ถ้ามี**

#### 🔬 การทดสอบข้อตกลงเบื้องต้น (สำคัญมากในภาคปฏิบัติ)

**(ก) ทดสอบการแจกแจงปกติ**

| สถิติทดสอบ | ใช้เมื่อ |
|---|---|
| **Kolmogorov–Smirnov** | n > 50 |
| **Shapiro–Wilk** | n ≤ 50 |

> H₀ : ข้อมูลมีการแจกแจงแบบปกติ
> H₁ : ข้อมูลไม่มีการแจกแจงแบบปกติ
>
> **อยาก "ผ่าน" ต้องได้ p-value > 0.05 (ยอมรับ H₀)** ← ตรงข้ามกับปกติ! ระวังสับสน

*คำสั่ง SPSS:* `Analyze > Descriptive Statistics > Explore…`

**(ข) ทดสอบความเท่ากันของความแปรปรวน (เฉพาะกรณี 2 ตัวอย่างอิสระ)**

| สถิติทดสอบ | **Levene's Test for Equality of Variances** |
|---|---|

> H₀ : ประชากรทุกกลุ่มมีความแปรปรวนเท่ากัน
> H₁ : ประชากรอย่างน้อย 1 กลุ่มมีความแปรปรวนแตกต่างจากกลุ่มอื่น
>
> - Sig. > 0.05 → ยอมรับ H₀ → **σ₁² = σ₂²** → อ่าน "Equal variances assumed"
> - Sig. ≤ 0.05 → ปฏิเสธ H₀ → **σ₁² ≠ σ₂²** → อ่าน "Equal variances not assumed"

---

### ขั้นที่ 4 : คำนวณค่าสถิติ และหาค่า p-value

> **p-value** คือ **ค่านัยสำคัญน้อยที่สุดที่ทำให้ปฏิเสธ H₀**
> หรือ ความน่าจะเป็นที่จะได้ค่าสถิติสุดโต่งเท่านี้หรือมากกว่า เมื่อ H₀ เป็นจริง

**วิธีคำนวณ p-value ด้วยมือ**

| รูปแบบ H₁ | p-value |
|---|---|
| H₁: θ > θ₀ | P(Z > Z₀) = 1 − P(Z < Z₀) |
| H₁: θ < θ₀ | P(Z < Z₀) |
| H₁: θ ≠ θ₀ | 2 × P(Z > \|Z₀\|) |

> 🔴 **จุดที่พลาดบ่อยที่สุด (เน้นย้ำในเอกสาร):**
> โปรแกรม SPSS/Excel รายงาน **Sig. (2-tailed)** เสมอ
> ถ้าเราทดสอบ **แบบทางเดียว** เราสนใจ *เพียงด้านเดียว* ของการแจกแจง (ซ้ายหรือขวา)
> **ดังนั้นต้องหารครึ่งของ p-value แบบสองทาง** เพื่อพิจารณาเฉพาะด้านที่เราสนใจ
>
> `p-value (ทางเดียว) = Sig.(2-tailed) / 2`

---

### ขั้นที่ 5 : ตัดสินใจและสรุปผล

**เกณฑ์การตัดสินใจมี 2 วิธี (ให้ผลตรงกันเสมอ)**

**วิธีที่ 1 — ใช้ p-value (นิยมที่สุด / ใช้กับ SPSS, Excel)**

```
ปฏิเสธ H₀   ถ้า   p-value ≤ α
```

**วิธีที่ 2 — ใช้บริเวณปฏิเสธ (Critical Region)**

| H₁ | กรณีใช้ Z | กรณีใช้ T |
|---|---|---|
| θ > θ₀ | ปฏิเสธ H₀ ถ้า **Z ≥ z_α** | ปฏิเสธ H₀ ถ้า **T ≥ t_(α, ν)** |
| θ < θ₀ | ปฏิเสธ H₀ ถ้า **Z ≤ −z_α** | ปฏิเสธ H₀ ถ้า **T ≤ −t_(α, ν)** |
| θ ≠ θ₀ | ปฏิเสธ H₀ ถ้า **Z ≥ z_(α/2)** หรือ **Z ≤ −z_(α/2)** | ปฏิเสธ H₀ ถ้า **T ≥ t_(α/2, ν)** หรือ **T ≤ −t_(α/2, ν)** |

**การเขียนสรุป (ต้องเขียนกลับเป็นภาษาโจทย์เสมอ!)**

> "…นั่นคือ **[ข้อสรุปในภาษาของโจทย์]** ที่ระดับนัยสำคัญ 0.05 (p < 0.05)"

❌ อย่าเขียนแค่ "ปฏิเสธ H₀" แล้วจบ — ต้องแปลกลับเป็นเรื่องราวของโจทย์

---

## 2.3 ⭐⭐ ตารางรวมตัวสถิติทดสอบทั้งหมด (Master Table)

### 🔷 (1) ค่าเฉลี่ยของ 1 ประชากร (μ)

| กรณี | เงื่อนไข | ตัวสถิติทดสอบ | df |
|---|---|---|---|
| 1 | ทราบ σ² (n เท่าใดก็ได้) | **Z = (X̄ − μ₀)/(σ/√n)** | — |
| 2 | ไม่ทราบ σ² และ n < 30 | **T = (X̄ − μ₀)/(S/√n)** | n − 1 |
| 3 | ไม่ทราบ σ² และ n ≥ 30 | **Z = (X̄ − μ₀)/(S/√n)** | — |

**ข้อตกลงเบื้องต้น:** ตัวอย่างขนาด n สุ่มมาจากประชากรที่มีการแจกแจงปกติ มีค่าเฉลี่ย μ และความแปรปรวน σ²

---

### 🔷 (2) ผลต่างค่าเฉลี่ยของ 2 ประชากร — ตัวอย่างอิสระกัน (μ₁ − μ₂)

| กรณี | เงื่อนไข | ตัวสถิติทดสอบ | df |
|---|---|---|---|
| 1 | ทราบ σ₁², σ₂² | **Z = [(X̄₁−X̄₂) − d₀] / √(σ₁²/n₁ + σ₂²/n₂)** | — |
| 2 | ไม่ทราบ σ₁², σ₂² แต่ **σ₁² ≠ σ₂²** | **T = [(X̄₁−X̄₂) − d₀] / √(S₁²/n₁ + S₂²/n₂)** | ν = Welch (ปัดเศษทิ้ง) |
| 3 | ไม่ทราบ σ₁², σ₂² แต่ **σ₁² = σ₂²** | **T = [(X̄₁−X̄₂) − d₀] / √(S²_p(1/n₁ + 1/n₂))** | ν = n₁ + n₂ − 2 |

```
S²_p = [ (n₁−1)S₁² + (n₂−1)S₂² ] / (n₁ + n₂ − 2)

         ( S₁²/n₁ + S₂²/n₂ )²
ν  =  ───────────────────────────────────
       (S₁²/n₁)²/(n₁−1) + (S₂²/n₂)²/(n₂−1)
```

**ข้อตกลงเบื้องต้น:** สุ่มตัวอย่างขนาด n₁ และ n₂ มาโดยอิสระกัน จากประชากรที่ 1 และ 2 ที่มีการแจกแจงปกติ มีค่าเฉลี่ย μ₁, μ₂ และความแปรปรวน σ₁², σ₂² ตามลำดับ

---

### 🔷 (3) ผลต่างค่าเฉลี่ยของ 2 ประชากร — ตัวอย่างสัมพันธ์กัน (μ_D)

| กรณี | เงื่อนไข | ตัวสถิติทดสอบ | df |
|---|---|---|---|
| 1 | n < 30 | **T = (D̄ − D₀)/(S_D/√n)** | n − 1 |
| 2 | n ≥ 30 | **Z = (D̄ − D₀)/(S_D/√n)** | — |

```
D̄ = ΣDᵢ/n        S²_D = [ ΣDᵢ² − (ΣDᵢ)²/n ] / (n−1)
```

---

### 🔷 (4) สัดส่วนของ 1 ประชากร (p)

```
                p̂ − p₀
Z  =  ───────────────────────       โดย  q₀ = 1 − p₀
          √( p₀q₀ / n )
```

> ⚠️ **ตอนทดสอบใช้ p₀q₀ (ค่าตาม H₀)** ไม่ใช่ p̂q̂
> เพราะเราคำนวณ "ภายใต้สมมติว่า H₀ เป็นจริง" ⇒ ต้องใช้ค่าความแปรปรวนตอน H₀ เป็นจริง
> (ต่างจากสูตร **CI** ที่ใช้ p̂q̂ เพราะไม่มี H₀ ให้อ้าง) ← **ข้อแตกต่างที่ออกสอบบ่อยมาก**

---

### 🔷 (5) ผลต่างสัดส่วนของ 2 ประชากร (p₁ − p₂)

**กรณีที่ d₀ = 0** (ทดสอบว่าเท่ากันหรือไม่ — พบบ่อยที่สุด)

```
                 p̂₁ − p̂₂                                     x₁ + x₂
Z  =  ─────────────────────────────       โดย   p̄  =  ─────────── ,  q̄ = 1 − p̄
       √( p̄ q̄ (1/n₁ + 1/n₂) )                            n₁ + n₂
```

**กรณีที่ d₀ ≠ 0**

```
             (p̂₁ − p̂₂) − d₀
Z  =  ──────────────────────────────
       √( p̂₁q̂₁/n₁ + p̂₂q̂₂/n₂ )
```

### 🧠 แนวคิด : ทำไม d₀ = 0 ต้องใช้ p̄ (pooled proportion)?

- ถ้า H₀: p₁ = p₂ เป็นจริง แปลว่าทั้ง 2 กลุ่มมาจากประชากรที่มีสัดส่วน **เดียวกัน**
- ⇒ เอาข้อมูลทั้ง 2 กลุ่มมา **รวมกัน** เพื่อประมาณสัดส่วนร่วมนั้น จะได้ค่าที่แม่นยำที่สุด
- ⇒ p̄ = (x₁+x₂)/(n₁+n₂) = จำนวนที่สนใจทั้งหมด / จำนวนตัวอย่างทั้งหมด
- แต่ถ้า d₀ ≠ 0 แปลว่า H₀ ไม่ได้บอกว่าทั้งสองเท่ากัน ⇒ pool ไม่ได้ ⇒ ใช้ p̂₁, p̂₂ แยกกัน

## 🟩 หมวด A : การประมาณค่า (CH4)

---

### 📘 ตัวอย่างที่ 1 — CI ของ μ กรณีทราบ σ (ใช้ z)

> **โจทย์** น้ำหนักสุทธิของน้ำตาลที่บรรจุถุงโดยเครื่องจักรเครื่องหนึ่ง มีการแจกแจงปกติ ที่มีค่าเบี่ยงเบนมาตรฐาน **1.2 ออนซ์** สุ่มน้ำตาลมา **25 ถุง** พบว่ามีน้ำหนักสุทธิเฉลี่ย **19.8 ออนซ์**
> จงหาช่วงความเชื่อมั่น **95%** ของน้ำหนักสุทธิเฉลี่ยของน้ำตาลที่บรรจุถุงโดยเครื่องจักรเครื่องนี้ทั้งหมด

#### 💡 แนวคิด (คิด 3 คำถามนี้เสมอ)

| คำถาม | คำตอบจากโจทย์ | ผลที่ได้ |
|---|---|---|
| 1. หาอะไร? | น้ำหนัก**เฉลี่ย** ของ **1 กลุ่ม** | → พารามิเตอร์คือ **μ** |
| 2. รู้ σ ไหม? | รู้! โจทย์บอก "ค่าเบี่ยงเบนมาตรฐาน 1.2" ของ**กระบวนการ** (ประชากร) | → **กรณีที่ 1** |
| 3. n เท่าไร? | n = 25 (แต่ไม่สำคัญ เพราะกรณี 1 ใช้ได้ทุก n) | → ใช้ **z** |

> 🔑 **จุดชี้ขาด:** คำว่า "มีการแจกแจงปกติที่มีค่าเบี่ยงเบนมาตรฐาน 1.2" = คุณสมบัติของ **ประชากร** → นั่นคือ **σ = 1.2** (ไม่ใช่ S)
> ถ้าโจทย์เขียนว่า "จากตัวอย่าง 25 ถุง มีส่วนเบี่ยงเบนมาตรฐาน 1.2" นั่นคือ **S** → ต้องใช้ **t** (กรณี 2) แทน!

#### ✍️ วิธีทำ

ให้ μ แทนน้ำหนักสุทธิเฉลี่ยของน้ำตาลที่บรรจุถุงโดยเครื่องจักรเครื่องนี้ทั้งหมด

**ขั้น 1** ระบุค่า : X̄ = 19.8 , σ = 1.2 , n = 25
**ขั้น 2** หาค่าวิกฤต : ความเชื่อมั่น 95% → α = 0.05 → α/2 = 0.025 → **z₀.₀₂₅ = 1.96**
**ขั้น 3** แทนค่าในสูตร

```
X̄ − z_(α/2)·(σ/√n)  <  μ  <  X̄ + z_(α/2)·(σ/√n)

19.8 − (1.96)(1.2/√25)  <  μ  <  19.8 + (1.96)(1.2/√25)

19.8 − (1.96)(0.24)     <  μ  <  19.8 + (1.96)(0.24)

19.8 − 0.4704           <  μ  <  19.8 + 0.4704

        19.33  <  μ  <  20.27
```

#### ✅ คำตอบ
**ที่ระดับความเชื่อมั่น 95% น้ำหนักสุทธิเฉลี่ยของน้ำตาลที่บรรจุถุงโดยเครื่องจักรเครื่องนี้ทั้งหมด มีค่าระหว่าง 19.33 ถึง 20.27 ออนซ์**

#### ⚠️ จุดที่มักพลาด
- ใช้ z₀.₀₅ = 1.645 แทน z₀.₀₂₅ = 1.96 (**ลืมหาร α ด้วย 2** เพราะ CI เป็นสองทางเสมอ)
- ลืมใส่ **√n** ใต้ σ (ใช้ 1.2 แทน 1.2/5)

### 📘 ตัวอย่างที่ 2 — CI ของ μ กรณีไม่ทราบ σ และ n < 30 (ใช้ t)

> **โจทย์** ในการศึกษาปริมาณการใช้น้ำมันในรถบรรทุกรุ่นใหม่ยี่ห้อหนึ่งรวม **10 คัน** โดยบันทึกระยะทางที่รถแต่ละคันแล่นได้ (หน่วย : ไมล์/แกลลอน) ดังนี้
>
> `18.6  18.4  19.2  20.8  19.4  20.5  18.7  19.3  19.6  20.2`
>
> จงหาช่วงความเชื่อมั่น **99%** ของระยะทางโดยเฉลี่ยที่รถบรรทุกรุ่นใหม่ยี่ห้อนี้แล่นได้

#### 💡 แนวคิด

| คำถาม | คำตอบ | ผล |
|---|---|---|
| 1. หาอะไร? | ระยะทาง**เฉลี่ย** 1 กลุ่ม | **μ** |
| 2. รู้ σ ไหม? | **ไม่รู้** — โจทย์ให้ข้อมูลดิบมา ต้องคำนวณ S เอง | ไม่ใช่กรณี 1 |
| 3. n เท่าไร? | n = 10 **< 30** | → **กรณีที่ 2 : ใช้ t, df = 9** |

> 🔑 **สัญญาณ "โจทย์ให้ข้อมูลดิบมาเป็นชุด"** = ต้องคำนวณ X̄ และ S เอง = **ไม่รู้ σ แน่นอน**

#### ✍️ วิธีทำ

ให้ X แทนระยะทางที่รถแต่ละคันแล่นได้ , μ แทนระยะทางโดยเฉลี่ยที่รถบรรทุกรุ่นนี้แล่นได้

**ขั้น 1 — คำนวณสถิติเชิงพรรณนา**

```
ΣX = 18.6+18.4+19.2+20.8+19.4+20.5+18.7+19.3+19.6+20.2 = 194.7

X̄ = 194.7 / 10 = 19.47

S = √{ [ΣX² − (ΣX)²/n] / (n−1) } ≈ 0.81   (คำนวณจริง = 0.8152)
```

**ขั้น 2 — หาค่าวิกฤต**
ความเชื่อมั่น 99% → α = 0.01 → α/2 = 0.005 , df = n−1 = 9
เปิดตาราง t : **t₀.₀₀₅, ₉ = 3.25**

**ขั้น 3 — แทนค่า**

```
X̄ − t_(α/2, n−1)·(S/√n)  <  μ  <  X̄ + t_(α/2, n−1)·(S/√n)

19.47 − (3.25)(0.81/√10)  <  μ  <  19.47 + (3.25)(0.81/√10)

19.47 − (3.25)(0.2561)    <  μ  <  19.47 + (3.25)(0.2561)

19.47 − 0.8325            <  μ  <  19.47 + 0.8325

        18.64  <  μ  <  20.30
```

#### ✅ คำตอบ
**ที่ระดับความเชื่อมั่น 99% ระยะทางโดยเฉลี่ยที่รถบรรทุกรุ่นใหม่ยี่ห้อนี้แล่นได้ มีค่าระหว่าง 18.64 ถึง 20.30 ไมล์/แกลลอน**

#### 📊 เทียบกับผลจาก Excel
`Data > Data Analysis > Descriptive Statistics` (ติ๊ก Confidence Level for Mean = 99%) จะได้
- Mean = 19.47 (การประมาณแบบจุด)
- Confidence Level(99.0%) = **0.8378** ← ตัวเลขนี้คือ *ครึ่งความกว้าง* ต้องเอาไปบวก/ลบเอง
- ⇒ CI = 19.47 ± 0.8378 = **(18.6322 , 20.3078)**

*(ต่างจากการคำนวณมือเล็กน้อย เพราะมือปัด S = 0.81 และ t = 3.25 ส่วน Excel ใช้ S = 0.8152, t = 3.2498)*

#### ⚠️ จุดที่มักพลาด
- ใช้ **z แทน t** เพราะเห็น "99%" แล้วรีบใส่ 2.576 → **ผิด** เพราะ n = 10 < 30 และไม่รู้ σ
- เปิดตาราง t ผิดบรรทัด — ต้องใช้ **df = n − 1 = 9** ไม่ใช่ 10
- คิดว่า Excel ให้ขอบเขตล่าง–บนมาแล้ว (จริง ๆ ให้แค่ margin of error)

### 📘 ตัวอย่างที่ 3 — CI ของ μ กรณีไม่ทราบ σ และ n ≥ 30 (กรณีศึกษาโควิด-19)

> **โจทย์** งานวิจัยเรื่อง *ผลกระทบจากการแพร่ระบาดของโรคโควิด-19 ต่อความเครียดของนักศึกษาระดับปริญญาตรี*
> สุ่มนักศึกษามา **150 คน** ได้คะแนนความเครียดเฉลี่ย **X̄ = 20.88** และ **S = 7.13**
> จงหา (ก) การประมาณแบบจุด (ข) ช่วงความเชื่อมั่น 99% ของความเครียดเฉลี่ย

#### 💡 แนวคิด
- ไม่รู้ σ (มีแต่ S จากตัวอย่าง) + **n = 150 ≥ 30** → **กรณีที่ 3 : ใช้ z คู่กับ S**
- นี่คือกรณีที่ "แทบไม่ต้องเปิดตาราง t เลย" เพราะ n ใหญ่มาก

#### ✍️ วิธีทำ

**(ก) การประมาณแบบจุด**

```
μ̂ = X̄ = ΣXᵢ/n = (21 + 25 + … + 26)/150 = 20.88
```
> **ดังนั้น ความเครียดเฉลี่ยที่นักศึกษาได้รับผลกระทบจากโควิด-19 ประมาณ 20.88 คะแนน**

**(ข) การประมาณแบบช่วง 99%**

α = 0.01 → α/2 = 0.005 → **z₀.₀₀₅ = 2.58**

```
X̄ − z_(α/2)·(S/√n)  <  μ  <  X̄ + z_(α/2)·(S/√n)

20.88 − (2.58)(7.13/√150)  <  μ  <  20.88 + (2.58)(7.13/√150)

20.88 − (2.58)(0.5822)     <  μ  <  20.88 + (2.58)(0.5822)

20.88 − 1.502              <  μ  <  20.88 + 1.502

        19.38  <  μ  <  22.38
```

#### ✅ คำตอบ
**ที่ระดับความเชื่อมั่น 99% ความเครียดเฉลี่ยที่นักศึกษาได้รับผลกระทบจากโควิด-19 ประมาณ 19.38 ถึง 22.38 คะแนน**

> 📊 **ผลจาก SPSS** (`Analyze > Descriptive Statistics > Explore…`) : Mean = 20.88 , 99% CI = (19.36 , 22.40)
> ต่างจากมือเล็กน้อยเพราะ SPSS ใช้ **t (df = 149)** ไม่ใช่ z — แต่ค่าใกล้เคียงกันมาก ยืนยันว่าการอนุโลมใช้ z เมื่อ n ≥ 30 สมเหตุสมผล

#### ⚠️ จุดที่มักพลาด
- **จำ 2.58 กับ 2.33 สลับกัน** : 2.58 = z₀.₀₀₅ (สองทาง 99%) , 2.33 = z₀.₀₁ (ทางเดียว)
- ลืมว่า S/√n ≠ S (ต้องหาร √150 = 12.247 ก่อน)

### 📘 ตัวอย่างที่ 4 — CI ของ μ₁ − μ₂ กรณีตัวอย่างอิสระ และ σ₁² ≠ σ₂² (⭐ ข้อยาก)

> **โจทย์** ในการศึกษาผลของการเรียนพิเศษหลังเลิกเรียน ต่อคะแนนสอบวิชาคณิตศาสตร์ของนักเรียนชั้น ม.3 โรงเรียนแห่งหนึ่ง โดยสุ่มนักเรียนมา 2 กลุ่ม คือ **กลุ่มที่เรียนพิเศษ 8 คน** และ **กลุ่มที่ไม่ได้เรียนพิเศษ 24 คน** โดยมีคะแนนสอบดังนี้
>
> - **กลุ่มที่เรียนพิเศษ:** 148, 171, 198, 168, 218, 236, 178, 264
> - **กลุ่มที่ไม่ได้เรียนพิเศษ:** 175, 172, 163, 181, 162, 152, 164, 180, 160, 174, 178, 148, 146, 176, 185, 158, 157, 164, 182, 170, 172, 178, 154, 148
>
> จงหาช่วงความเชื่อมั่น **90%** ของผลต่างของค่าเฉลี่ยคะแนนสอบ **เมื่อทราบว่าความแปรปรวนของทั้งสองกลุ่มไม่เท่ากัน (σ₁² ≠ σ₂²)**

#### 💡 แนวคิด (คิด 4 ชั้น)

| ชั้น | คำถาม | คำตอบ |
|---|---|---|
| 1 | 1 หรือ 2 ประชากร? | **2** (เรียนพิเศษ vs ไม่เรียน) |
| 2 | อิสระ หรือ จับคู่? | **อิสระ** — คนละกลุ่ม, n₁=8 ≠ n₂=24 |
| 3 | รู้ σ₁², σ₂² ไหม? | **ไม่รู้** (มีแต่ข้อมูลดิบ) |
| 4 | σ₁² = σ₂² หรือไม่? | โจทย์บอกชัดว่า **≠** → **กรณีที่ 3 : Welch's t** |

> 🔑 **สังเกตด้วยตาเปล่าก็ได้:** กลุ่มเรียนพิเศษคะแนนกระจายจาก 148–264 (กว้างมาก) แต่กลุ่มไม่เรียนอยู่ 146–185 (แคบ) → ความแปรปรวนต่างกันชัดเจน สมเหตุสมผลกับที่โจทย์บอก

#### ✍️ วิธีทำ

ให้ μ₁ และ μ₂ แทนคะแนนสอบเฉลี่ยของนักเรียนที่เรียนพิเศษ และไม่ได้เรียนพิเศษ ตามลำดับ

**ขั้น 1 — สรุปสถิติของแต่ละกลุ่ม (ใช้สูตรลัด S²)**

กลุ่มที่ 1 : n₁ = 8 , ΣX₁ = 1,581 , ΣX₁² = 323,173

```
X̄₁ = 1,581 / 8 = 197.625

S₁² = [ ΣX₁² − (ΣX₁)²/n₁ ] / (n₁−1) = [ 323,173 − (1,581)²/8 ] / 7 = 1,532.55
```

กลุ่มที่ 2 : n₂ = 24 , ΣX₂ = 4,035 , ΣX₂² = 681,537

```
X̄₂ = 4,035 / 24 = 168.125

S₂² = [ ΣX₂² − (ΣX₂)²/n₂ ] / (n₂−1) = [ 681,537 − (4,035)²/24 ] / 23 = 137.07
```

**ผลต่างของค่าเฉลี่ย :  X̄₁ − X̄₂ = 197.625 − 168.125 = 29.5**

**ขั้น 2 — คำนวณองศาเสรีแบบ Welch**

```
        ( S₁²/n₁ + S₂²/n₂ )²             ( 1,532.55/8 + 137.07/24 )²
ν  =  ─────────────────────────────  =  ────────────────────────────────────────
       (S₁²/n₁)²/(n₁−1) + (S₂²/n₂)²/(n₂−1)   (1,532.55/8)²/7 + (137.07/24)²/23

                 (191.569 + 5.711)²           (197.280)²        38,919.4
              = ─────────────────────  =  ───────────────  =  ──────────  =  7.42
                 36,698.7/7 + 32.61/23      5,242.7 + 1.418      5,244.1

ν = 7.42  ≈  7      (มีเศษให้ปัดทิ้ง)
```

**ขั้น 3 — หาค่าวิกฤต**
ความเชื่อมั่น 90% → α = 0.10 → α/2 = 0.05 , ν = 7 → **t₀.₀₅, ₇ = 1.895**

**ขั้น 4 — แทนค่าในสูตร**

```
(X̄₁ − X̄₂) ± t_(α/2, ν)·√( S₁²/n₁ + S₂²/n₂ )

29.5 ± 1.895·√( 1,532.55/8 + 137.07/24 )

29.5 ± 1.895·√( 197.28 )

29.5 ± 1.895 × 14.046

29.5 ± 26.62

        2.88  <  μ₁ − μ₂  <  56.12
```

#### ✅ คำตอบ
**ที่ระดับความเชื่อมั่น 90% ผลต่างของค่าเฉลี่ยคะแนนสอบระหว่างนักเรียนที่เรียนพิเศษและไม่ได้เรียนพิเศษ มีค่าระหว่าง 2.88 ถึง 56.12 คะแนน**

#### 🔍 การตีความ (สำคัญ!)
ช่วงนี้ **เป็นบวกทั้งช่วง (ไม่คลุม 0)** ⇒ สรุปได้ว่า **นักเรียนที่เรียนพิเศษมีคะแนนเฉลี่ยสูงกว่ากลุ่มที่ไม่ได้เรียนพิเศษอย่างมีนัยสำคัญ** (ที่ระดับ 0.10 แบบสองทาง)

#### ⚠️ จุดที่มักพลาด
1. **คำนวณ ν แล้วปัดขึ้น** — เอกสารระบุชัด "**ถ้ามีเศษให้ปัดทิ้ง**" (7.42 → 7 ไม่ใช่ 8) เพราะปัดลงจะได้ t ใหญ่ขึ้น = ระมัดระวังมากขึ้น
2. **ใช้ S²_p ทั้งที่โจทย์บอก σ₁² ≠ σ₂²** — pool ไม่ได้เด็ดขาด
3. **เอา S₁²/n₁ + S₂²/n₂ แล้วลืมถอด √**
4. สับสน **S² กับ S** ในการแทนค่า

### 📘 ตัวอย่างที่ 5 — CI ของ μ₁ − μ₂ จาก SPSS (กรณีศึกษาโควิด-19)

#### 💡 แนวคิด
- 2 กลุ่ม (ชาย/หญิง) คนละคน → **ตัวอย่างอิสระ** → ใช้ `Independent-Samples T Test`

**ขั้น 1 — ตรวจการแจกแจงปกติ**
- นศ.ชาย (n ≤ 50 ใช้ Shapiro-Wilk) : p-value = **0.195 > 0.05** → ยอมรับ H₀ → ปกติ ✔

```
การประมาณแบบจุด :   X̄₁ − X̄₂ = 3.368

การประมาณแบบช่วง 95% :

#### ⚠️ จุดที่มักพลาด
- **อ่านบรรทัดผิด** — ดู Levene ก่อนเสมอ ห้ามเดา
- สับสนว่า Levene Sig. > 0.05 แปลว่าอะไร → **> 0.05 = ความแปรปรวนเท่ากัน = อ่านบรรทัดบน**

### 📘 ตัวอย่างที่ 6 — CI ของ μ_D (ตัวอย่างสัมพันธ์กัน : ดนตรีบำบัด)

### 📘 ตัวอย่างที่ 7 — CI ของ p (สัดส่วน 1 ประชากร)

> **โจทย์** จากการสอบถามแม่บ้านในจังหวัดขอนแก่นจำนวน **400 คน** ว่าเป็นโรคความดันโลหิตสูงหรือไม่ ปรากฏว่ามีแม่บ้าน **224 คน** เป็นโรคความดันโลหิตสูง
> จงหาช่วงความเชื่อมั่น **90%** ของสัดส่วนของแม่บ้านทั้งหมดในจังหวัดขอนแก่นที่เป็นโรคความดันโลหิตสูง

#### 💡 แนวคิด
- คำถามเป็นแบบ **"เป็น / ไม่เป็น"** (นับหัว) → ข้อมูลเชิงกลุ่ม → พารามิเตอร์คือ **p** ไม่ใช่ μ
- สัดส่วน **ใช้ z เสมอ** (ไม่มีกรณี t)

#### ✍️ วิธีทำ

ให้ p แทนสัดส่วนของแม่บ้านที่เป็นโรคความดันโลหิตสูง

**ขั้น 1 — ประมาณแบบจุด**
```
p̂ = x/n = 224/400 = 0.56       ดังนั้น  q̂ = 1 − p̂ = 1 − 0.56 = 0.44
```

**ขั้น 2 — ค่าวิกฤต**
ความเชื่อมั่น 90% → α = 0.10 → α/2 = 0.05 → **z₀.₀₅ = 1.645**

**ขั้น 3 — แทนค่า**
```
p̂ − z_(α/2)·√(p̂q̂/n)  <  p  <  p̂ + z_(α/2)·√(p̂q̂/n)

0.56 − 1.645·√( (0.56)(0.44)/400 )  <  p  <  0.56 + 1.645·√( (0.56)(0.44)/400 )

0.56 − 1.645·√( 0.000616 )          <  p  <  0.56 + 1.645·√( 0.000616 )

0.56 − 1.645(0.02482)               <  p  <  0.56 + 1.645(0.02482)

0.56 − 0.0408                       <  p  <  0.56 + 0.0408

        0.52  <  p  <  0.60
```

#### ✅ คำตอบ
**ที่ระดับความเชื่อมั่น 90% สัดส่วนของแม่บ้านทั้งหมดในจังหวัดขอนแก่นที่เป็นโรคความดันโลหิตสูง มีค่าระหว่าง 0.52 ถึง 0.60** (หรือ 52% ถึง 60%)

#### ⚠️ จุดที่มักพลาด
- ลืมหาร **n** ใน √(p̂q̂/n) → ได้ช่วงกว้างเวอร์
- ใช้ **t** เพราะติดนิสัยจากเรื่องค่าเฉลี่ย → สัดส่วนไม่มี t
- แปลง % ผิด (0.56 ≠ 56 ในสูตร ต้องใช้ทศนิยม)

### 📘 ตัวอย่างที่ 8 — CI ของ p₁ − p₂ (ผลต่างสัดส่วน 2 ประชากร)

> **โจทย์** จากการสุ่มวัยรุ่นในจังหวัดหนึ่ง **เพศหญิง 600 คน** และ **เพศชาย 400 คน** แล้วสอบถามว่าชมข่าวโทรทัศน์ภาคค่ำเป็นประจำหรือไม่ ปรากฏว่ามีวัยรุ่นเพศ**หญิง 300 คน** และเพศ**ชาย 100 คน** ชมรายการดังกล่าวเป็นประจำ
> จงหาช่วงความเชื่อมั่น **99%** ของผลต่างของสัดส่วนวัยรุ่นเพศหญิงและชายทั้งหมดในจังหวัดนี้ที่ชมข่าวโทรทัศน์ภาคค่ำเป็นประจำ

#### 💡 แนวคิด
- 2 กลุ่ม + ตัวแปรแบบ "ชม/ไม่ชม" → **p₁ − p₂**
- โจทย์ถาม "หญิงและชาย" ตามลำดับ ⇒ ตั้ง **1 = หญิง , 2 = ชาย** (ลำดับสำคัญต่อเครื่องหมายคำตอบ!)

#### ✍️ วิธีทำ

ให้ p₁ และ p₂ แทนสัดส่วนวัยรุ่นเพศหญิงและชายทั้งหมดในจังหวัดนี้ที่ชมข่าวโทรทัศน์ภาคค่ำเป็นประจำ

**ขั้น 1 — ประมาณแบบจุด**
```
p̂₁ = 300/600 = 0.50     →   q̂₁ = 0.50
p̂₂ = 100/400 = 0.25     →   q̂₂ = 0.75

p̂₁ − p̂₂ = 0.50 − 0.25 = 0.25
```

**ขั้น 2 — ค่าวิกฤต**
ความเชื่อมั่น 99% → α = 0.01 → α/2 = 0.005 → **z₀.₀₀₅ = 2.576**

**ขั้น 3 — แทนค่า**
```
(p̂₁ − p̂₂) ± z_(α/2)·√( p̂₁q̂₁/n₁ + p̂₂q̂₂/n₂ )

0.25 ± 2.576·√( (0.5)(0.5)/600 + (0.25)(0.75)/400 )

0.25 ± 2.576·√( 0.00041667 + 0.00046875 )

0.25 ± 2.576·√( 0.00088542 )

0.25 ± 2.576 (0.029756)

0.25 ± 0.0767

        0.17  <  p₁ − p₂  <  0.33
```

#### ✅ คำตอบ
**ที่ระดับความเชื่อมั่น 99% ผลต่างของสัดส่วนวัยรุ่นเพศหญิงและชายทั้งหมดในจังหวัดนี้ที่ชมข่าวโทรทัศน์ภาคค่ำเป็นประจำ มีค่าระหว่าง 0.17 ถึง 0.33**

#### 🔍 การตีความ
ช่วงเป็นบวกทั้งช่วง (ไม่คลุม 0) ⇒ **สัดส่วนวัยรุ่นหญิงที่ชมข่าว สูงกว่าชายอย่างมีนัยสำคัญ** ประมาณ 17–33 จุดร้อยละ

#### ⚠️ จุดที่มักพลาด
- **บวกความแปรปรวน แต่ไปเขียนลบ** → Var ของผลต่างต้อง **บวก** เสมอ
- ใส่ n สลับกลุ่ม (เอา 600 ไปหารกับสัดส่วนของชาย)
- สลับ 1 กับ 2 ทำให้เครื่องหมายกลับ → ถ้าตั้ง 1 = ชาย จะได้ (−0.33 , −0.17) ซึ่งก็ถูกเช่นกัน แต่ต้องตีความให้สอดคล้อง

### 📗 ตัวอย่างที่ 9 — ทดสอบ μ ของ 1 ประชากร (สองทาง)

> **โจทย์** จากการศึกษาความเครียดในกลุ่มนักศึกษา มหาวิทยาลัย A ที่ประเทศตุรกีในช่วงการระบาดของโควิด-19 พบว่านักศึกษามีคะแนนความเครียดเฉลี่ยเท่ากับ **22.74 (SD: 6.26)**
> อยากทราบว่า **นักศึกษา [ในงานวิจัยนี้] มีคะแนนความเครียดเฉลี่ย แตกต่างไปจากรายงานความเครียดของนักศึกษามหาวิทยาลัย A หรือไม่?** ที่ระดับนัยสำคัญ 0.05

#### 💡 แนวคิด
- เทียบ **1 กลุ่ม** กับ **ค่ามาตรฐานที่รู้อยู่แล้ว (22.74)** → ทดสอบ **μ ของ 1 ประชากร**
- คำว่า **"แตกต่างไปจาก"** → ไม่ระบุทิศทาง → **สองทาง (≠)**
- ไม่รู้ σ ของประชากรเรา + n = 150 ≥ 30 → **กรณีที่ 3 (ใช้ z กับ S)** ; SPSS ใช้ t df=149 ซึ่งค่าใกล้เคียงกัน

#### ✍️ วิธีทำ (5 ขั้นตอน)

**ขั้นที่ 1 — กำหนดสมมติฐาน**
```
H₀ : μ = 22.74
H₁ : μ ≠ 22.74          (สองทาง)
```

**ขั้นที่ 2 — ระดับนัยสำคัญ**  α = 0.05

**ขั้นที่ 3 — เลือกตัวสถิติทดสอบและเกณฑ์ตัดสินใจ**
- ตรวจข้อตกลงเบื้องต้นก่อน (n = 150 > 50 → ใช้ **Kolmogorov–Smirnov**)
  - H₀: ข้อมูลมีการแจกแจงปกติ → **p-value = 0.200 > 0.05 → ยอมรับ H₀**
  - ✔ คะแนนความเครียดมีการแจกแจงปกติ ⇒ ใช้ t/z test ได้
- ตัวสถิติทดสอบ (ไม่ทราบ σ², n ≥ 30) :

```
Z = (X̄ − μ₀)/(S/√n)
```

- เกณฑ์ : **ปฏิเสธ H₀ ถ้า p-value ≤ α** (หรือ |Z| ≥ z₀.₀₂₅ = 1.96)

**ขั้นที่ 4 — คำนวณค่าสถิติและ p-value**
```
X̄ = 20.88 ,  S = 7.126 ,  n = 150 ,  μ₀ = 22.74

Z = (20.88 − 22.74) / (7.126/√150)
  = (−1.86) / (7.126/12.247)
  = (−1.86) / 0.582
  = −3.195

p-value = 2 × P(Z < −3.195) ≈ 2 × 0.0007 = 0.0014
```
📊 **SPSS** (`One-Sample T Test`, Test Value = 22.74) รายงาน **Sig. (2-tailed) = 0.002** (df = 149)

**ขั้นที่ 5 — ตัดสินใจและสรุป**
```
p-value = 0.002  <  α = 0.05   →   ปฏิเสธ H₀
```

#### ✅ คำตอบ
**คะแนนความเครียดเฉลี่ยของนักศึกษาในรัฐนิวเจอร์ซี แตกต่างจากกลุ่มนักศึกษาในประเทศตุรกี ที่ระดับนัยสำคัญ 0.05 (p < 0.05)**
(ทิศทาง: 20.88 < 22.74 ⇒ กลุ่มนิวเจอร์ซีเครียด **น้อยกว่า**)

#### ⚠️ จุดที่มักพลาด
- ตั้ง H₀: μ = 20.88 (**เอาค่าจากตัวอย่างมาตั้ง**) → ผิด! H₀ ต้องเป็นค่าอ้างอิงจากภายนอก (22.74)
- ลืมคูณ 2 ตอนหา p-value ของการทดสอบสองทาง
- ใช้ SD = 6.26 (ของตุรกี) มาคำนวณ → ต้องใช้ S = 7.126 ของกลุ่มเราเอง

### 📗 ตัวอย่างที่ 10 — ทดสอบ μ₁ − μ₂ (ตัวอย่างอิสระกัน)

> **โจทย์** อยากทราบว่า **นักศึกษาชาย และ นักศึกษาหญิง มีคะแนนความเครียดเฉลี่ยแตกต่างกันหรือไม่?** ที่ระดับนัยสำคัญ 0.05

#### 💡 แนวคิด
- 2 กลุ่ม คนละคน → **อิสระกัน** → `Independent-Samples T Test`
- "แตกต่างกันหรือไม่" → **สองทาง**
- ต้องเช็ก 2 assumption : (1) แจกแจงปกติทั้ง 2 กลุ่ม (2) ความแปรปรวนเท่ากันไหม (Levene)

#### ✍️ วิธีทำ

**ขั้นที่ 1 — กำหนดสมมติฐาน**
```
H₀ : μ_ชาย − μ_หญิง = 0
H₁ : μ_ชาย − μ_หญิง ≠ 0
```

**ขั้นที่ 2 — ระดับนัยสำคัญ**  α = 0.05

**ขั้นที่ 3 — เลือกตัวสถิติทดสอบ**

*(ก) ทดสอบการแจกแจงปกติ* (n ≤ 50 → Shapiro-Wilk , n > 50 → K-S)
- นศ.ชาย : p-value = **0.195 > 0.05** → ยอมรับ H₀ → **ปกติ ✔**
- นศ.หญิง : p-value = **0.877 > 0.05** → ยอมรับ H₀ → **ปกติ ✔**

*(ข) ทดสอบความเท่ากันของความแปรปรวน (Levene's Test)*
- H₀ : ประชากรทุกกลุ่มมีความแปรปรวนเท่ากัน
- F = 0.033 , **Sig. = 0.856 > 0.05** → **ยอมรับ H₀ → σ₁² = σ₂²**

*(ค) จึงเลือก* **กรณีที่ 3 : ไม่ทราบ σ² แต่ทราบว่า σ₁² = σ₂²**
```
T = [(X̄₁ − X̄₂) − d₀] / √( S²_p (1/n₁ + 1/n₂) )        ,  ν = n₁ + n₂ − 2 = 148

โดย  S²_p = [ (n₁−1)S₁² + (n₂−1)S₂² ] / (n₁ + n₂ − 2)
```
- เกณฑ์ : ปฏิเสธ H₀ ถ้า p-value ≤ α

**ขั้นที่ 4 — คำนวณ (จาก SPSS: Equal variances assumed)**
```
Mean Difference = 3.368
Std. Error Difference = 1.252

t = 3.368 / 1.252 = 2.690      ,  df = 148

Sig. (2-tailed) = 0.008
```

**ขั้นที่ 5 — ตัดสินใจและสรุป**
```
p-value = 0.008  <  α = 0.05   →   ปฏิเสธ H₀
```

#### ✅ คำตอบ
**นักศึกษาชายมีคะแนนความเครียดเฉลี่ยแตกต่างไปจากนักศึกษาหญิง ที่ระดับนัยสำคัญ 0.05 (p < 0.05)**
โดยชายสูงกว่าหญิงเฉลี่ย **3.368 คะแนน** และ 95% CI = **(0.894 , 5.842)** ซึ่ง **ไม่คลุม 0** → สอดคล้องกับผลการทดสอบ ✔

#### ⚠️ จุดที่มักพลาด
- **ข้ามการทดสอบ Levene** แล้วเลือกสูตรมั่ว
- อ่าน Sig. ของ **Levene** (0.856) ไปสรุปผลการทดสอบค่าเฉลี่ย → ผิดคนละคอลัมน์! ต้องอ่าน **Sig. (2-tailed) ของ t-test = 0.008**
- ถ้าโจทย์ถามแบบ **ทางเดียว** (เช่น "ชายเครียดมากกว่าหญิงหรือไม่") ต้องเอา **0.008/2 = 0.004** ไปเทียบกับ α

### 📗 ตัวอย่างที่ 11 — ทดสอบ μ_D (ตัวอย่างสัมพันธ์กัน : ดนตรีบำบัด)

> **โจทย์** ผู้วิจัยจัดโปรแกรมการบำบัดความเครียดโดยใช้ "ดนตรีบำบัด" ให้นักศึกษากลุ่มตัวอย่าง
> อยากทราบว่า **โปรแกรมการบำบัดความเครียดมีประสิทธิภาพในการลดความเครียดให้นักศึกษากลุ่มตัวอย่างหรือไม่?** ที่ระดับนัยสำคัญ 0.05

#### 💡 แนวคิด
- วัด **ก่อน–หลัง** ในคนเดียวกัน → **Paired-Samples T Test**
- "มีประสิทธิภาพ**ในการลด**" → ระบุทิศทาง → **ทางเดียว**
- 🔴 **ต้องกำหนดนิยาม D ให้ชัดก่อนตั้ง H₁** :
  - ถ้า **D = ก่อน − หลัง** → "ลดลง" หมายถึงก่อนมากกว่าหลัง → **H₁ : μ_D > 0**
  - ถ้า **D = หลัง − ก่อน** → "ลดลง" หมายถึงหลังน้อยกว่าก่อน → **H₁ : μ_D < 0**
  - *(สไลด์เขียน H₁ : μ_D < 0 ซึ่งสอดคล้องกับนิยาม D = หลัง − ก่อน ส่วน SPSS ในสไลด์คำนวณ Pair = "ก่อน − หลัง" จึงได้ t เป็นบวก (+4.781) — **ข้อสรุปเหมือนกัน** แต่เวลาสอบต้องเขียนนิยาม D ให้ตรงกับ H₁ ที่ตั้ง)*

#### ✍️ วิธีทำ

**ขั้นที่ 1 — กำหนดสมมติฐาน** *(ใช้นิยาม D = ก่อน − หลัง)*
```
H₀ : μ_D = 0            (โปรแกรมไม่มีผล)
H₁ : μ_D > 0            (ก่อนเครียดมากกว่าหลัง = โปรแกรมลดความเครียดได้)
```

**ขั้นที่ 2 — ระดับนัยสำคัญ**  α = 0.05

**ขั้นที่ 3 — เลือกตัวสถิติทดสอบ**

*(ก) ทดสอบการแจกแจงปกติของคะแนนก่อนและหลัง*
- H₀: คะแนน (ก่อน) มีการแจกแจงปกติ → **p-value = 0.200 > 0.05 → ยอมรับ H₀ ✔**
- H₀: คะแนน (หลัง) มีการแจกแจงปกติ → **p-value = 0.200 > 0.05 → ยอมรับ H₀ ✔**

*(ข) เลือกสูตร* : n = 150 ≥ 30 → **กรณีที่ 2**
```
Z = (D̄ − D₀)/(S_D/√n)          [SPSS ใช้ T ที่ df = n−1 = 149 ซึ่งให้ผลใกล้เคียงกัน]
```
- เกณฑ์ : ปฏิเสธ H₀ ถ้า p-value ≤ α *(ทางเดียว ⇒ p = Sig.(2-tailed)/2)*

**ขั้นที่ 4 — คำนวณ**
```
X̄_ก่อน = 20.88 ,  X̄_หลัง = 18.23   →   D̄ = 2.647
S_D = 6.779  ,  SE = S_D/√n = 6.779/√150 = 0.554  ,  n = 150

t = (2.647 − 0) / 0.554 = 4.781      ,  df = 149

Sig. (2-tailed) = 0.000  →  ทางเดียว : p-value = 0.000/2 < 0.0001
```

**ขั้นที่ 5 — ตัดสินใจและสรุป**
```
p-value < 0.0001  <  α = 0.05   →   ปฏิเสธ H₀
```

#### ✅ คำตอบ
**โปรแกรมการบำบัดความเครียดมีประสิทธิภาพในการลดความเครียดให้นักศึกษา ที่ระดับนัยสำคัญ 0.05 (p < 0.05)**
โดยลดลงเฉลี่ย 2.647 คะแนน และ 95% CI ของผลต่าง = (1.553 , 3.740) ซึ่งเป็นบวกทั้งช่วง ✔

#### ⚠️ จุดที่มักพลาด
- **ใช้ Independent-Samples T Test** ทั้งที่เป็นข้อมูลก่อน–หลังของคนเดียวกัน
- ลืมหาร 2 เพราะเป็นการทดสอบทางเดียว
- **นิยาม D กลับด้าน** แล้วตีความว่า "โปรแกรมทำให้เครียดมากขึ้น" → ต้องเช็กเครื่องหมายของ D̄ ให้ตรงกับที่ตั้ง H₁

### 📗 ตัวอย่างที่ 12 — ทดสอบ p (สัดส่วน 1 ประชากร, ทางเดียว)

> **โจทย์** เกณฑ์ประเมินความเครียด ระบุว่า เมื่อคะแนนความเครียด ≥ 20 คะแนน จะถือว่ามีความเครียด
> อยากทราบว่า **นักศึกษามีความเครียดเกินร้อยละ 50 หรือไม่?** ที่ระดับนัยสำคัญ 0.05

#### 💡 แนวคิด
- นับหัวว่า "เครียด/ไม่เครียด" → พารามิเตอร์คือ **p**
- **"เกินร้อยละ 50"** → ระบุทิศทาง "มากกว่า" → **ทางเดียว หางขวา** และ **p₀ = 0.50**
- ใช้ **z เสมอ** และ **ตัวส่วนใช้ p₀q₀** (ไม่ใช่ p̂q̂)

#### ✍️ วิธีทำ

**ขั้นที่ 1 — กำหนดสมมติฐาน**
```
H₀ : p = 0.5
H₁ : p > 0.5            (ทางเดียว หางขวา)
```

**ขั้นที่ 2 — ระดับนัยสำคัญ**  α = 0.05

**ขั้นที่ 3 — เลือกตัวสถิติทดสอบ**
```
            p̂ − p₀
Z  =  ─────────────────        โดย  q₀ = 1 − p₀ = 0.5
        √( p₀q₀/n )
```
- เกณฑ์ : ปฏิเสธ H₀ ถ้า p-value ≤ α (หรือ Z ≥ z₀.₀₅ = **1.65**)

**ขั้นที่ 4 — คำนวณค่าสถิติและ p-value**
```
แทนค่า :   Z₀ = (p̂ − 0.5) / √( (0.5)(0.5)/150 )  =  2.32

หา p-value (ทางเดียว หางขวา) :

p-value = P(Z > Z₀) = P(Z > 2.32)
        = 1 − P(Z < 2.32)
        = 1 − 0.9898
        = 0.0102
```
📊 **SPSS** (`Analyze > Compare Means and Proportions > One-Sample Proportions…`, Test Value = 0.5) รายงาน **p-value < 0.01**

**ขั้นที่ 5 — ตัดสินใจและสรุป**
```
p-value = 0.0102  <  α = 0.05   →   ปฏิเสธ H₀
```
*(หรือเทียบบริเวณวิกฤต : Z₀ = 2.32 > 1.65 → ตกในบริเวณปฏิเสธ H₀)*

#### ✅ คำตอบ
**นักศึกษามีความเครียดเกินร้อยละ 50 ที่ระดับนัยสำคัญ 0.05 (p < 0.05)**

> 📎 **หมายเหตุการคำนวณ:** ถ้าคำนวณ p̂ จากข้อมูลแยกเพศในตัวอย่างที่ 13 จะได้ p̂ = (74+27)/150 = 101/150 = 0.673
> ⇒ Z₀ = (0.673 − 0.5)/√(0.25/150) = 4.25 , p-value < 0.0001 ซึ่งตรงกับที่ SPSS รายงานว่า p < 0.01
> **ไม่ว่าจะใช้ตัวเลขชุดใด ข้อสรุปเหมือนกันคือ "ปฏิเสธ H₀"**

#### ⚠️ จุดที่มักพลาด
- **ใช้ p̂q̂ ในตัวส่วนแทน p₀q₀** ← พลาดกันมากที่สุด! จำว่า *ทดสอบใช้ p₀ , ทำ CI ใช้ p̂*
- ใช้ z₀.₀₂₅ = 1.96 ทั้งที่เป็นการทดสอบทางเดียว (ต้องใช้ z₀.₀₅ = 1.645)
- คูณ p-value ด้วย 2 ทั้งที่เป็นทางเดียว

### 📗 ตัวอย่างที่ 13 — ทดสอบ p₁ − p₂ (ผลต่างสัดส่วน 2 ประชากร)

> **โจทย์** เกณฑ์การประเมินความเครียด ระบุว่า เมื่อคะแนนความเครียด ≥ 20 คะแนน จะถือว่ามีความเครียด
> อยากทราบว่า **นักศึกษาชาย กับ นักศึกษาหญิง มีสัดส่วนความเครียดแตกต่างกันหรือไม่?** ที่ระดับนัยสำคัญ 0.05
>
> **ข้อมูล:** นักศึกษาชาย 106 คน มีความเครียด 74 คน | นักศึกษาหญิง 44 คน มีความเครียด 27 คน

#### 💡 แนวคิด
- 2 กลุ่ม + ตัวแปรนับหัว (เครียด/ไม่เครียด) → **p₁ − p₂**
- "แตกต่างกันหรือไม่" → **สองทาง**
- H₀ อ้างว่า p₁ − p₂ = **0** ⇒ **d₀ = 0 ⇒ ต้องใช้ p̄ (pooled)**

#### ✍️ วิธีทำ

ให้ p̂₁ แทนสัดส่วนของนักศึกษาชายที่มีความเครียด , p̂₂ แทนสัดส่วนของนักศึกษาหญิงที่มีความเครียด

**ขั้นที่ 1 — กำหนดสมมติฐาน**
```
H₀ : p₁ − p₂ = 0
H₁ : p₁ − p₂ ≠ 0          (สองทาง)
```

**ขั้นที่ 2 — ระดับนัยสำคัญ**  α = 0.05

**ขั้นที่ 3 — เลือกตัวสถิติทดสอบ**  (เนื่องจาก d₀ = 0)
```
              (p̂₁ − p̂₂) − 0                            x₁ + x₂
Z  =  ───────────────────────────       โดย   p̄  =  ───────────
        √( p̄ q̄ (1/n₁ + 1/n₂) )                          n₁ + n₂
```
- เกณฑ์ : ปฏิเสธ H₀ ถ้า p-value ≤ α (หรือ Z > 1.96 หรือ Z < −1.96)

**ขั้นที่ 4 — คำนวณค่าสถิติและ p-value**
```
p̂₁ = 74/106 = 0.698        p̂₂ = 27/44 = 0.614
p̂₁ − p̂₂ = 0.698 − 0.614 = 0.084

p̄ = (74 + 27)/(106 + 44) = 101/150 = 0.673      →   q̄ = 0.327

               0.698 − 0.614 − 0
Z₀  =  ───────────────────────────────────────
        √( (0.673)(1 − 0.673) × (1/106 + 1/44) )

               0.084                  0.084
    =  ─────────────────────  =  ────────────  =  0.999  ≈  1.00
        √( 0.2201 × 0.03216 )        0.0841
```

**หา p-value** — เนื่องจากสมมติฐานต้องการศึกษาแบบ **Two-tailed**
```
p-value = P(Z > Z₀) = P(Z > 1)
        = 1 − P(Z < 1)
        = 1 − 0.8413
        = 0.1587

⇒ สองทาง :  0.1587 × 2 = 0.3174
```
📊 **SPSS** (`Independent-Samples Proportions…`) รายงาน **p-value = 0.315**

**ขั้นที่ 5 — ตัดสินใจและสรุป**
```
p-value = 0.315  >  α = 0.05   →   ยอมรับ H₀
```
*(หรือ |Z₀| = 1.00 < 1.96 → ตกในบริเวณยอมรับ H₀)*

#### ✅ คำตอบ
**นักศึกษาชาย กับ นักศึกษาหญิง มีสัดส่วนความเครียด "ไม่แตกต่างกัน" (p > 0.05)**

**ผลประกอบจาก SPSS**
- การประมาณแบบจุด : p̂₁ − p̂₂ = 0.698 − 0.614 = **0.084**
- การประมาณแบบช่วง 95% : **−0.084 < p₁ − p₂ < 0.253** → **คลุม 0** ⇒ สอดคล้องกับการยอมรับ H₀ ✔

#### 🔍 ข้อสังเกตสำคัญ (ออกสอบชอบถาม)
สังเกตว่า **ค่าเฉลี่ยคะแนน**ความเครียดของชายกับหญิง **ต่างกัน** (ตัวอย่างที่ 10, p = 0.008)
แต่ **สัดส่วนผู้ที่ "มีความเครียด" ไม่ต่างกัน** (ข้อนี้, p = 0.315)
> **ทำไม?** เพราะการแปลงคะแนนต่อเนื่อง → ตัวแปรทวิภาค (≥20 / <20) **ทำให้สูญเสียสารสนเทศ** อำนาจการทดสอบจึงลดลง
> **บทเรียน:** ถ้ามีข้อมูลเชิงปริมาณอยู่แล้ว อย่าเพิ่งแปลงเป็นกลุ่มโดยไม่จำเป็น

#### ⚠️ จุดที่มักพลาด
- **ใช้ √(p̂₁q̂₁/n₁ + p̂₂q̂₂/n₂) ทั้งที่ d₀ = 0** → ต้องใช้ p̄ แบบ pooled
- คำนวณ p̄ ผิดเป็น (p̂₁ + p̂₂)/2 → **ผิด!** ต้องถ่วงน้ำหนักด้วย n : p̄ = (x₁+x₂)/(n₁+n₂)
- ลืมคูณ 2 ในการทดสอบสองทาง

## 4.2 ตารางสรุป "เลือก z หรือ t"

| สถานการณ์ | ใช้ | df |
|---|---|---|
| ทราบ σ² (μ หรือ μ₁−μ₂) | **z** | — |
| ไม่ทราบ σ² , n < 30 , 1 ประชากร | **t** | n − 1 |
| ไม่ทราบ σ² , n ≥ 30 , 1 ประชากร | **z** | — |
| ไม่ทราบ σ² , 2 ประชากรอิสระ , σ₁² = σ₂² | **t** | n₁ + n₂ − 2 |

| จับคู่ , n ≥ 30 | **z** | — |
| สัดส่วน (ทุกกรณี) | **z** | — |

> 🧲 **จำสั้น ๆ:** "**สัดส่วนใช้ z เสมอ — ค่าเฉลี่ยใช้ t เมื่อไม่รู้ σ และ n เล็ก**"

# ส่วนที่ 6 : สูตรรวมหน้าเดียว (Cheat Sheet)

## 📄 CH4 — ช่วงความเชื่อมั่น (1−α)100%

| พารามิเตอร์ | เงื่อนไข | สูตร CI |
|---|---|---|
| **μ** | ทราบ σ² (ทุก n) | X̄ ± z_(α/2)·σ/√n |
| **μ** | ไม่ทราบ σ², n < 30 | X̄ ± t_(α/2, n−1)·S/√n |
| **μ** | ไม่ทราบ σ², n ≥ 30 | X̄ ± z_(α/2)·S/√n |
| **μ₁−μ₂** | ทราบ σ₁², σ₂² | (X̄₁−X̄₂) ± z_(α/2)·√(σ₁²/n₁ + σ₂²/n₂) |
| **μ₁−μ₂** | ไม่ทราบ, σ₁² = σ₂² | (X̄₁−X̄₂) ± t_(α/2, n₁+n₂−2)·√(S²_p(1/n₁ + 1/n₂)) |
| **μ₁−μ₂** | ไม่ทราบ, σ₁² ≠ σ₂² | (X̄₁−X̄₂) ± t_(α/2, ν)·√(S₁²/n₁ + S₂²/n₂) |
| **μ_D** | n < 30 | D̄ ± t_(α/2, n−1)·S_D/√n |
| **μ_D** | n ≥ 30 | D̄ ± z_(α/2)·S_D/√n |
| **p** | ทุกกรณี | p̂ ± z_(α/2)·√(p̂q̂/n) |
| **p₁−p₂** | ทุกกรณี | (p̂₁−p̂₂) ± z_(α/2)·√(p̂₁q̂₁/n₁ + p̂₂q̂₂/n₂) |

**สูตรช่วย**
```
S² = [ΣX² − (ΣX)²/n]/(n−1)

S²_p = [(n₁−1)S₁² + (n₂−1)S₂²]/(n₁+n₂−2)

ν = (S₁²/n₁ + S₂²/n₂)² / [ (S₁²/n₁)²/(n₁−1) + (S₂²/n₂)²/(n₂−1) ]   ← ปัดเศษทิ้ง

S²_D = [ΣD² − (ΣD)²/n]/(n−1)
```

## 📄 CH5 — ตัวสถิติทดสอบ

| พารามิเตอร์ | เงื่อนไข | ตัวสถิติทดสอบ |
|---|---|---|
| **μ** | ทราบ σ² | Z = (X̄ − μ₀)/(σ/√n) |
| **μ** | ไม่ทราบ σ², n < 30 | T = (X̄ − μ₀)/(S/√n) , df = n−1 |
| **μ** | ไม่ทราบ σ², n ≥ 30 | Z = (X̄ − μ₀)/(S/√n) |
| **μ₁−μ₂** | ทราบ σ₁², σ₂² | Z = [(X̄₁−X̄₂) − d₀]/√(σ₁²/n₁ + σ₂²/n₂) |
| **μ₁−μ₂** | σ₁² ≠ σ₂² | T = [(X̄₁−X̄₂) − d₀]/√(S₁²/n₁ + S₂²/n₂) , df = ν |
| **μ₁−μ₂** | σ₁² = σ₂² | T = [(X̄₁−X̄₂) − d₀]/√(S²_p(1/n₁+1/n₂)) , df = n₁+n₂−2 |
| **μ_D** | n < 30 | T = (D̄ − D₀)/(S_D/√n) , df = n−1 |
| **μ_D** | n ≥ 30 | Z = (D̄ − D₀)/(S_D/√n) |
| **p** | — | Z = (p̂ − p₀)/√(p₀q₀/n) |
| **p₁−p₂** | d₀ = 0 | Z = (p̂₁ − p̂₂)/√(p̄q̄(1/n₁+1/n₂)) , p̄ = (x₁+x₂)/(n₁+n₂) |
| **p₁−p₂** | d₀ ≠ 0 | Z = [(p̂₁−p̂₂) − d₀]/√(p̂₁q̂₁/n₁ + p̂₂q̂₂/n₂) |

**กฎการตัดสินใจ:  ปฏิเสธ H₀ ถ้า p-value ≤ α**
