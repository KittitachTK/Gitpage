## 0. แผนที่ความคิด — "เจอโจทย์แบบไหน ใช้สูตรอะไร"

ก่อนลงมือทำทุกข้อ ให้ถาม 3 คำถามนี้ตามลำดับเสมอ

**คำถามที่ 1 : ตัวสถิติที่โจทย์ถามคืออะไร?**

| โจทย์ถามถึง | ตัวสถิติ | ค่าคาดหมาย | ความคลาดเคลื่อนมาตรฐาน (S.E.) |
|---|---|---|---|
| ค่าเฉลี่ยกลุ่มเดียว | $\bar{X}$ | $\mu$ | $\sigma/\sqrt{n}$ |
| ผลต่างค่าเฉลี่ย 2 กลุ่ม | $\bar{X}_1-\bar{X}_2$ | $\mu_1-\mu_2$ | $\sqrt{\dfrac{\sigma_1^2}{n_1}+\dfrac{\sigma_2^2}{n_2}}$ |
| สัดส่วนกลุ่มเดียว | $\hat{p}$ | $p$ | $\sqrt{\dfrac{p(1-p)}{n}}$ |
| ผลต่างสัดส่วน 2 กลุ่ม | $\hat{p}_1-\hat{p}_2$ | $p_1-p_2$ | $\sqrt{\dfrac{p_1q_1}{n_1}+\dfrac{p_2q_2}{n_2}}$ |

**คำถามที่ 2 : ทราบ $\sigma$ (ของประชากร) หรือไม่?**

- **ทราบ $\sigma$** → ใช้ **Z** เสมอ (ไม่ว่า n เท่าไร ถ้าประชากรปกติ)
- **ไม่ทราบ $\sigma$ ใช้ S แทน**
  - $n \ge 30$ → ใช้ **Z** ได้ (อาศัย CLT)
  - $n < 30$ + ประชากรปกติ → ต้องใช้ **t** ที่ $df = n-1$

**คำถามที่ 3 : เขียนสูตรมาตรฐานแล้วเปิดตาราง**

$$Z \text{ หรือ } T=\frac{\text{ตัวสถิติ} - \text{ค่าคาดหมาย}}{\text{S.E.}}$$

> ⚠️ **ตาราง Z ที่ใช้ในวิชานี้เป็นแบบ "พื้นที่จาก 0 ถึง z"** (ไม่ใช่แบบสะสมจาก $-\infty$) ดังนั้นต้องบวก/ลบ 0.5 เองเสมอ และใช้ความสมมาตร $P(Z<-z)=P(Z>z)$

# ส่วนที่ 1 : การแจกแจงของค่าเฉลี่ยตัวอย่าง $\bar{X}$

## ตัวอย่าง 1 (กรณีทราบ $\sigma^2$) — คะแนนสอบภาษาอังกฤษ

> คะแนนสอบมีการแจกแจงปกติ $\mu = 500$, $\sigma = 100$ สุ่มมา $n = 25$ คน
> ก. $P(\bar{X} > 555)$   ข. $P(490 < \bar{X} < 515)$

**วิธีคิด**
ทราบ $\sigma$ และประชากรปกติ → ใช้ Z ได้ทันที ไม่ต้องสนใจว่า n เล็ก

$$\bar{X}\sim N\!\left(500,\ \frac{100^2}{25}\right),\qquad \text{S.E.}=\frac{\sigma}{\sqrt{n}}=\frac{100}{5}=20$$

**ข้อ ก.**

$$Z=\frac{555-500}{20}=2.75$$

$$P(\bar{X}>555)=P(Z>2.75)=0.5-P(0<Z<2.75)=0.5-0.4970=\boxed{0.0030}$$

**ข้อ ข.**

$$Z_1=\frac{490-500}{20}=-0.50,\qquad Z_2=\frac{515-500}{20}=0.75$$

ค่า z คร่อม 0 → **แยกเป็นสองฝั่งแล้วบวกกัน**

$$P(-0.50<Z<0.75)=P(0<Z<0.50)+P(0<Z<0.75)=0.1915+0.2734=\boxed{0.4649}$$

💡 *จุดที่มักผิด:* ลืมหาร $\sigma$ ด้วย $\sqrt{n}$ แล้วใช้ $\sigma=100$ ตรง ๆ — จำไว้ว่าโจทย์ถามถึง **ค่าเฉลี่ยของตัวอย่าง** ไม่ใช่คะแนนของคนคนเดียว

---

## ตัวอย่าง 2 (ไม่ทราบ $\sigma^2$, n เล็ก) — ส่วนสูงนักเรียนอนุบาล

> ส่วนสูงแจกแจงปกติ $\mu = 130$ ซม. สุ่ม $n = 25$ คน ได้ $S = 6$
> จงหา $P(\bar{X} > 131.1)$

**วิธีคิด**
ไม่ทราบ $\sigma$ + $n = 25 < 30$ + ประชากรปกติ → **ต้องใช้ t** ที่ $df = n-1 = 24$

$$T=\frac{\bar{X}-\mu}{S/\sqrt{n}}=\frac{131.1-130}{6/\sqrt{25}}=\frac{1.1}{1.2}=0.9167$$

เปิดตาราง t แถว $df = 24$ : $t_{0.25,24}=0.685$ และ $t_{0.10,24}=1.318$

เนื่องจาก $0.685 < 0.9167 < 1.318$ ตารางไม่มีค่าตรงพอดี จึงตอบเป็น **ช่วง**

$$\boxed{0.10 < P(\bar{X}>131.1) < 0.25}$$

*(ค่าจริงจาก Excel `=1-T.DIST(0.9167,24,TRUE)` $\approx 0.1842$ — อยู่ในช่วงที่ตอบ ✓)*

💡 *จุดที่มักผิด:* ตอบเป็นตัวเลขเดี่ยวทั้งที่ใช้ตาราง t — ตาราง t ให้เฉพาะค่าวิกฤต จึงตอบได้แค่ช่วง

---

## ตัวอย่าง 3 (ไม่ทราบ $\sigma^2$, n ใหญ่ — CLT) — รายได้ครัวเรือน

> รายได้ต่อเดือน **ไม่ได้แจกแจงปกติ** $\mu = 10{,}000$ บาท สุ่ม $n = 100$ ครัวเรือน ได้ $S = 4{,}800$
> จงหา $P(\bar{X} < 10{,}500)$

**วิธีคิด**
ประชากรไม่ปกติ **แต่** $n = 100 \ge 30$ → อาศัย **CLT** ให้ $\bar{X}$ ปกติโดยประมาณ และใช้ $S$ แทน $\sigma$ ได้ → ใช้ **Z**

$$\text{S.E.}=\frac{S}{\sqrt{n}}=\frac{4800}{10}=480$$

$$Z=\frac{10500-10000}{480}=1.0417\approx 1.04$$

$$P(\bar{X}<10500)=P(Z<1.04)=0.5+P(0<Z<1.04)=0.5+0.3508=\boxed{0.8508}$$

💡 *จุดสังเกต:* น้อยกว่าค่าที่มากกว่าค่าเฉลี่ย → คำตอบต้องมากกว่า 0.5 เสมอ ใช้เช็กความสมเหตุสมผล

# ส่วนที่ 2 : การแจกแจงของผลต่างค่าเฉลี่ย $\bar{X}_1-\bar{X}_2$

## ตัวอย่าง 1 (ทราบ $\sigma_1^2,\sigma_2^2$) — นิโคตินในบุหรี่ A vs B

> A : $\mu_1 = 22$, $\sigma_1^2 = 36$ | B : $\mu_2 = 23$, $\sigma_2^2 = 64$ | $n_1=n_2=100$ (ประชากรไม่ปกติ)
> จงหาความน่าจะเป็นที่นิโคตินเฉลี่ยของ A ต่างจาก B ไม่เกิน 0.5 mg. คือ $P(\bar{X}_1-\bar{X}_2 < 0.5)$

**วิธีคิด**
$n_1,n_2$ ใหญ่ → CLT → $\bar{X}_1-\bar{X}_2$ ปกติโดยประมาณ

$$E(\bar{X}_1-\bar{X}_2)=\mu_1-\mu_2=22-23=-1$$

$$\text{S.E.}=\sqrt{\frac{\sigma_1^2}{n_1}+\frac{\sigma_2^2}{n_2}}=\sqrt{\frac{36}{100}+\frac{64}{100}}=\sqrt{1}=1$$

$$Z=\frac{0.5-(-1)}{1}=1.5$$

$$P(\bar{X}_1-\bar{X}_2<0.5)=P(Z<1.5)=0.5+0.4332=\boxed{0.9332}$$

💡 *จุดที่มักผิด:* **บวก** ความแปรปรวนเสมอแม้จะเป็นผลต่าง ($\text{Var}(\bar{X}_1-\bar{X}_2)=\text{Var}(\bar{X}_1)+\text{Var}(\bar{X}_2)$ เพราะสุ่มอิสระกัน) — ห้ามลบ

---

## ตัวอย่าง 2 (ไม่ทราบ $\sigma^2$ แต่ทราบว่า $\sigma_1^2=\sigma_2^2$) — เงินเดือนบริษัท A vs B

> A : $\mu_1 = 9{,}900$, $n_1=15$, $S_1=250$ | B : $\mu_2 = 9{,}300$, $n_2=10$, $S_2=200$ (ประชากรปกติทั้งคู่)
> จงหา $P(\bar{X}_1-\bar{X}_2 > 450)$

**วิธีคิด**
ไม่ทราบ $\sigma$ + n เล็กทั้งคู่ + ทราบว่าความแปรปรวนเท่ากัน → ใช้ **t แบบรวมความแปรปรวน (pooled)** ที่ $df=n_1+n_2-2$

**ขั้นที่ 1 — หา $S_p^2$**

$$S_p^2=\frac{(n_1-1)S_1^2+(n_2-1)S_2^2}{n_1+n_2-2}=\frac{14(250)^2+9(200)^2}{23}=\frac{875{,}000+360{,}000}{23}=53{,}695.65$$

$$S_p=231.72,\qquad df=15+10-2=23$$

**ขั้นที่ 2 — หา S.E.**

$$\text{S.E.}=S_p\sqrt{\frac{1}{n_1}+\frac{1}{n_2}}=231.72\sqrt{\frac{1}{15}+\frac{1}{10}}=231.72(0.4082)=94.60$$

**ขั้นที่ 3 — แปลงเป็น t**

$$T=\frac{450-(9900-9300)}{94.60}=\frac{450-600}{94.60}=-1.586$$

**ขั้นที่ 4 — เปิดตาราง**
$-1.586$ เป็นลบ ใช้ความสมมาตร : $P(T_{23}>-1.586)=1-P(T_{23}>1.586)$

ตาราง $df=23$ : $t_{0.10}=1.319$, $t_{0.05}=1.714$ และ $1.319<1.586<1.714$

$$0.05<P(T_{23}>1.586)<0.10 \;\Longrightarrow\; \boxed{0.90 < P(\bar{X}_1-\bar{X}_2>450) < 0.95}$$

*(ค่าจริง $\approx 0.9368$ ✓)*

💡 *จุดที่มักผิด:* ลืมลบ $(\mu_1-\mu_2)=600$ ในตัวเศษ ทำให้ได้ t เป็นบวกและตอบผิดข้าง

---

# ส่วนที่ 3 : การแจกแจงของสัดส่วนตัวอย่าง $\hat{p}$

## ตัวอย่าง 3 — นักศึกษาเรียนต่อปริญญาโท

> $p = 0.30$, สุ่ม $n = 60$ คน

**ตั้งต้น**

$$\hat{p}\sim N\!\left(0.3,\ \frac{(0.3)(0.7)}{60}\right),\qquad \text{S.E.}=\sqrt{\frac{0.21}{60}}=\sqrt{0.0035}=0.0592$$

**ข้อ 1) $P(0.25<\hat{p}<0.35)$**

$$Z_1=\frac{0.25-0.30}{0.0592}=-0.85,\qquad Z_2=\frac{0.35-0.30}{0.0592}=0.85$$

$$P=P(0<Z<0.85)+P(0<Z<0.85)=0.3023+0.3023=\boxed{0.6046}$$

**ข้อ 2) $P(\hat{p}>0.2)$**

$$Z=\frac{0.20-0.30}{0.0592}=-1.69$$

$$P(Z>-1.69)=0.5+P(0<Z<1.69)=0.5+0.4545=\boxed{0.9545}$$

💡 *จุดสังเกต:* ข้อ 1 ช่วง 0.25–0.35 สมมาตรรอบ $p=0.3$ พอดี → $|Z|$ เท่ากันทั้งสองข้าง คำนวณครั้งเดียวแล้วคูณ 2 ได้เลย

---

# ส่วนที่ 4 : การแจกแจงของผลต่างสัดส่วน $\hat{p}_1-\hat{p}_2$

## ตัวอย่าง 4 — วิตามินซีกับการเป็นหวัด

> กลุ่มได้วิตามินซี $p_1 = 0.15$ | กลุ่มไม่ได้ $p_2 = 0.20$ | $n_1=n_2=50$
> จงหา $P(\hat{p}_1-\hat{p}_2 < 0.05)$

**วิธีคิด**

$$E(\hat{p}_1-\hat{p}_2)=0.15-0.20=-0.05$$

$$\text{S.E.}=\sqrt{\frac{(0.15)(0.85)}{50}+\frac{(0.20)(0.80)}{50}}=\sqrt{0.00255+0.0032}=\sqrt{0.00575}=0.0758$$

$$Z=\frac{0.05-(-0.05)}{0.0758}=1.32$$

$$P(Z<1.32)=0.5+P(0<Z<1.32)=0.5+0.4066=\boxed{0.9066}$$

💡 *จุดที่มักผิด:* คิด S.E. โดยใช้สัดส่วนรวม (pooled proportion) — ใน Chapter 3 ยังไม่ใช้ pooled เพราะโจทย์ให้ $p_1,p_2$ มาแล้ว (pooled จะไปใช้ตอนทดสอบสมมติฐาน)

# ส่วนที่ 5 : แบบฝึกการใช้ตาราง t ในบทเรียน (สไลด์ 20–28)

**หลักสำคัญ 3 ข้อ**
1. ตาราง t ให้ **พื้นที่หางขวา** : ค่าในตารางคือ $t_{\alpha,v}$ ที่ทำให้ $P(T_v > t_{\alpha,v}) = \alpha$
2. **สมมาตรรอบ 0** : $P(T_v < -t_{\alpha}) = P(T_v > t_{\alpha}) = \alpha$
3. หางซ้าย/สะสม ต้องแปลงเป็นหางขวาก่อนเสมอ : $P(T_v<t)=1-P(T_v>t)$

| ข้อ | โจทย์ | วิธีคิด | คำตอบ |
|---|---|---|---|
| 1 | $P(T_6 > 3.143)$ | เปิดแถว $v=6$ หา 3.1427 → อยู่คอลัมน์ $\alpha=0.01$ | **0.01** |
| 2 | $P(T_8 < -1.860)$ | สมมาตร → $=P(T_8>1.860)$ แถว 8 มี 1.8595 ที่ $\alpha=0.05$ | **0.05** |
| 3 | Excel `=T.DIST(-1.86, 8, TRUE)` | T.DIST แบบ TRUE = ความน่าจะเป็นสะสม (หางซ้าย) | **0.0500** |
| 4 | $P(T_{15} < 1.7531)$ (Excel) | สะสมถึงค่าบวก | **0.9500** |
| 5 | $P(T_{15} > 1.753)$ | $=1-P(T_{15}<1.753)=1-0.95$ | **0.05** |
| 6 | $P(-1.476 < T_5 < 2.015)$ | $=1-P(T_5<-1.476)-P(T_5>2.015)$ ; แถว 5 : $1.4759\to\alpha=0.10$, $2.0150\to\alpha=0.05$ | $1-0.10-0.05=$ **0.85** |
| 7 | หา $a$ เมื่อ $P(T_{10}<t_a)=0.975$ | สะสม 0.975 → หางขวา $=1-0.975=0.025$ → $a=0.025$ | $a=0.025$, $t_a=$ **2.2281** |
| 8 | หา $t_a$ เมื่อ $P(-t_a<T_{20}<t_a)=0.99$ | กลาง 0.99 → เหลือหางสองข้าง 0.01 → หางเดียว $0.01/2=0.005$ | $t_a=$ **2.8453** |

# ส่วนที่ 6 : แบบฝึกหัดท้ายบท — การแจกแจงปกติมาตรฐาน (Z)

> ใช้ตารางแบบ **พื้นที่จาก 0 ถึง z** และสมบัติ $P(Z<-z)=P(Z>z)$

### 1) $P(Z \le 1.71)$
ค่าเป็นบวกและถามฝั่งซ้าย → ครึ่งซ้ายทั้งหมด (0.5) บวกพื้นที่ 0 ถึง 1.71
$$=0.5+0.4564=\boxed{0.9564}$$

### 2) $P(Z \ge -1.71)$
ใช้สมมาตร : พื้นที่ทางขวาของ $-1.71$ เท่ากับพื้นที่ทางซ้ายของ $+1.71$
$$=P(Z\le 1.71)=\boxed{0.9564}$$

### 3) $P(Z \ge 1)$
หางขวา → ครึ่งขวาลบพื้นที่ 0 ถึง 1
$$=0.5-0.3413=\boxed{0.1587}$$

### 4) $P(0 < Z < 1)$
อ่านจากตารางตรง ๆ (นี่คือค่าที่ตารางให้พอดี)
$$=\boxed{0.3413}$$

### 5) $P(1.21 < Z < 1.78)$
ทั้งสองค่าอยู่ฝั่งเดียวกัน (ขวาทั้งคู่) → **ลบกัน**
$$=0.4625-0.3869=\boxed{0.0756}$$

### 6) $P(Z<-1.90 \text{ หรือ } Z>2.11)$
เป็นสองหางที่ไม่ทับกัน → หาแยกแล้วบวก
$$=(0.5-0.4713)+(0.5-0.4826)=0.0287+0.0174=\boxed{0.0461}$$

### 7) $P(|X-5|>6)$ เมื่อ $X\sim N(5,9)$
**ขั้นที่ 1** อ่านค่าพารามิเตอร์ : $\mu=5$, $\sigma^2=9 \Rightarrow \sigma=3$ (ระวัง! ตัวหลังใน $N(\cdot,\cdot)$ คือความแปรปรวน)
**ขั้นที่ 2** แกะค่าสัมบูรณ์ : $|X-5|>6 \iff X<-1$ หรือ $X>11$
**ขั้นที่ 3** แปลงเป็น Z : $Z=\dfrac{X-5}{3}$ → $Z<-2$ หรือ $Z>2$
$$=2\big[0.5-P(0<Z<2)\big]=2(0.5-0.4772)=\boxed{0.0456}$$

💡 *ทางลัด:* $P(|X-\mu|>k\sigma)=2P(Z>k)$ ในที่นี้ $6=2\sigma$ พอดี

# ส่วนที่ 7 : แบบฝึกหัดท้ายบท — การแจกแจงแบบ t

> **ค่าที่ต้องใช้จากตาราง**
> $df=10$ : $t_{0.20}=0.8791$, $t_{0.10}=1.3722$, $t_{0.05}=1.8125$, $t_{0.025}=2.2281$, $t_{0.01}=2.7638$, $t_{0.005}=3.1693$
> $df=18$ : $t_{0.005}=2.8784$

### 1) $P(T_{10} < -t_a) = 0.10$ → หา $t_a$
สมมาตร : $P(T_{10}<-t_a)=P(T_{10}>t_a)=\alpha$ → $a=0.10$
$$t_a=\boxed{1.3722}$$

### 2) $P(T_{10} > t_a) = 0.20$ → หา $t_a$
รูปแบบมาตรฐานของตารางเลย (หางขวา) → $a=0.20$
$$t_a=\boxed{0.8791}$$

### 3) $P(T_{10} > -t_a) = 0.80$ → หา $t_a$
พื้นที่ทางขวาของค่าลบ = 0.80 → พื้นที่หางซ้าย $=1-0.80=0.20$
$$P(T_{10}<-t_a)=0.20 \Rightarrow a=0.20,\quad t_a=\boxed{0.8791}$$

### 4) $P(-t_a < T_{10} < t_a) = 0.90$ → หา $t_a$
กลาง 0.90 → สองหางรวม 0.10 → **หางเดียว 0.05**
$$a=0.05,\quad t_a=\boxed{1.8125}$$

### 5) $P(-t_a < T_{18} < t_a) = 0.99$ → หา $t_a$
กลาง 0.99 → สองหางรวม 0.01 → หางเดียว 0.005
$$a=0.005,\quad t_a=\boxed{2.8784}$$

### 6) $P(T_8 < -1.8595)$
สมมาตร → $=P(T_8>1.8595)$ ; แถว $df=8$ ค่า 1.8595 อยู่คอลัมน์ $\alpha=0.05$
$$=\boxed{0.05}$$

### 7) $P(T_{15} < 1.7531)$
เป็นสะสมของค่าบวก ต้องกลับด้าน : $=1-P(T_{15}>1.7531)$ ; แถว 15 ค่า 1.7531 อยู่ที่ $\alpha=0.05$
$$=1-0.05=\boxed{0.95}$$

### 8) $P(-1.476 < T_5 < 2.015)$
ตัดหางสองข้างออกจาก 1 ; แถว $df=5$ : $1.4759\to\alpha=0.10$, $2.0150\to\alpha=0.05$
$$=1-P(T_5<-1.476)-P(T_5>2.015)=1-0.10-0.05=\boxed{0.85}$$

## สรุปข้อผิดพลาดที่พบบ่อยที่สุด 6 ข้อ

1. **ลืมหาร $\sqrt{n}$** — โจทย์ถามค่าเฉลี่ยตัวอย่าง ไม่ใช่ค่าเดี่ยว
2. **สับสน $\sigma$ กับ $\sigma^2$** — $N(5,9)$ หมายถึง $\sigma=3$ ไม่ใช่ 9
3. **ลบความแปรปรวนตอนหาผลต่าง** — ต้องบวกเสมอ
4. **ใช้ Z ทั้งที่ n < 30 และไม่ทราบ $\sigma$** — ต้องใช้ t, $df=n-1$
5. **ใช้ตาราง Z ผิดชนิด** — ตารางในวิชานี้ให้พื้นที่จาก 0 ถึง z ต้องบวก/ลบ 0.5 เอง
6. **ตอบตัวเลขเดี่ยวจากตาราง t** — ถ้าค่าไม่ตรงในตาราง ให้ตอบเป็นช่วง
