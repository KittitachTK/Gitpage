## ✅ เฉลยข้อ 1 — หลอดไฟ (One-Sample T Test, ทดสอบสองทาง)

> โจทย์: โรงงานอ้างว่า μ = 1,000 ชม. สงสัยว่า "ไม่เท่ากับ" ที่อ้าง | n=25, X̄=980, S=35, α=0.05

**ขั้นที่ 1 — กำหนดสมมติฐาน** *(2 คะแนน)*
```
H₀ : μ = 1000
H₁ : μ ≠ 1000        (สองทาง เพราะโจทย์ถาม "แตกต่างไปจาก...หรือไม่")
```

**ขั้นที่ 2 — ระดับนัยสำคัญ** *(1 คะแนน)*
```
α = 0.05
```

**ขั้นที่ 3 — เลือกตัวสถิติทดสอบและเกณฑ์การตัดสินใจ** *(2 คะแนน)*
- ไม่ทราบค่า σ² ของประชากร และ **n = 25 < 30** → ต้องใช้ **การแจกแจง t**
- ข้อมูลผ่านการทดสอบว่าแจกแจงปกติแล้ว (โจทย์ระบุ) ⇒ ใช้ t-test ได้

```
T = (X̄ − μ₀) / (S/√n)      ,  df = n − 1 = 24
```
เกณฑ์ : ปฏิเสธ H₀ ถ้า **p-value ≤ α** (หรือ |T| ≥ t₀.₀₂₅,₂₄ = 2.064)

**ขั้นที่ 4 — คำนวณค่าสถิติและหาค่า p-value** *(3 คะแนน)*
```
SE = S/√n = 35/√25 = 35/5 = 7

T = (980 − 1000) / 7 = −20/7 = −2.857

df = 24
```
เปิดตาราง t หรือคำนวณ : |T| = 2.857 > t₀.₀₂₅,₂₄ = 2.064
⇒ ตกอยู่ในบริเวณปฏิเสธ H₀ (p-value ≈ 0.0087 ซึ่งน้อยกว่า 0.05 มาก)

**ขั้นที่ 5 — ตัดสินใจและสรุปผล** *(2 คะแนน)*
```
|T| = 2.857  >  t_crit = 2.064   (หรือ p-value ≈ 0.009 < α = 0.05)
∴ ปฏิเสธ H₀
```
**สรุป:** อายุการใช้งานเฉลี่ยของหลอดไฟที่ผลิตจริง **แตกต่างไปจาก** 1,000 ชั่วโมงที่โรงงานอ้างไว้ อย่างมีนัยสำคัญทางสถิติที่ระดับ 0.05 (โดยอายุการใช้งานเฉลี่ยจากตัวอย่างต่ำกว่าที่อ้างไว้ คือ 980 ชั่วโมง)

## ✅ เฉลยข้อ 2 — เปรียบเทียบวิธีสอน A กับ B (Independent-Samples T Test)

> โจทย์: n₁=15, X̄₁=82.5, S₁=8.2 (วิธี A) ; n₂=18, X̄₂=74.1, S₂=9.5 (วิธี B) ; Levene's Sig.=0.581 ; α=0.05

**ขั้นที่ 1 — กำหนดสมมติฐาน** *(2 คะแนน)*
```
H₀ : μ_A − μ_B = 0
H₁ : μ_A − μ_B ≠ 0        (สองทาง เพราะโจทย์ถาม "แตกต่างกันหรือไม่")
```

**ขั้นที่ 2 — ระดับนัยสำคัญ** *(1 คะแนน)*
```
α = 0.05
```

**ขั้นที่ 3 — เลือกตัวสถิติทดสอบและเกณฑ์การตัดสินใจ** *(2 คะแนน)*

*ตรวจข้อตกลงเบื้องต้น — ความเท่ากันของความแปรปรวน (Levene's Test)*
```
H₀ : σ₁² = σ₂²      H₁ : σ₁² ≠ σ₂²
Levene's Sig. = 0.581 > 0.05  →  ยอมรับ H₀  →  σ_A² = σ_B²  (ความแปรปรวนเท่ากัน)
```

เนื่องจากตัวอย่างเป็นอิสระกัน (คนละคนกัน), ไม่ทราบ σ₁²,σ₂² แต่ทราบว่า σ₁²=σ₂² → **ใช้กรณีที่ 3 (pooled variance)**

```
T = [(X̄₁ − X̄₂) − 0] / √( S²ₚ (1/n₁ + 1/n₂) )     , df = n₁+n₂−2 = 31

โดย  S²ₚ = [ (n₁−1)S₁² + (n₂−1)S₂² ] / (n₁+n₂−2)
```
เกณฑ์ : ปฏิเสธ H₀ ถ้า p-value ≤ α (หรือ |T| ≥ t₀.₀₂₅,₃₁ = 2.040)

**ขั้นที่ 4 — คำนวณค่าสถิติและหาค่า p-value** *(3 คะแนน)*
```
S²ₚ = [ (15−1)(8.2)² + (18−1)(9.5)² ] / (15+18−2)
    = [ 14×67.24 + 17×90.25 ] / 31
    = [ 941.36 + 1534.25 ] / 31
    = 2475.61 / 31
    = 79.86

SE = √( S²ₚ (1/n₁ + 1/n₂) ) = √( 79.86 × (1/15 + 1/18) ) = √( 79.86 × 0.1222 ) = √9.76 = 3.12

T = (82.5 − 74.1) / 3.12 = 8.4 / 3.12 = 2.69

df = 31
```
|T| = 2.69 > t₀.₀₂₅,₃₁ = 2.040  ⇒ p-value ≈ 0.011 < 0.05

*(95% CI ของ μ_A−μ_B = 8.4 ± 2.040×3.12 = 8.4 ± 6.37 = (2.03, 14.77) — ไม่คลุม 0 ยืนยันผลเดียวกัน)*

**ขั้นที่ 5 — ตัดสินใจและสรุปผล** *(2 คะแนน)*
```
|T| = 2.69  >  t_crit = 2.040   (หรือ p-value ≈ 0.011 < α = 0.05)
∴ ปฏิเสธ H₀
```
**สรุป:** คะแนนสอบเฉลี่ยของนักเรียนที่เรียนด้วยวิธีสอน A **แตกต่างไปจาก** วิธีสอน B อย่างมีนัยสำคัญทางสถิติที่ระดับ 0.05 (โดยวิธี A ให้คะแนนเฉลี่ยสูงกว่าวิธี B อยู่ประมาณ 8.4 คะแนน)

## ✅ เฉลยข้อ 3 — สัดส่วนสินค้าชำรุด (One-Proportion Z-Test, ทดสอบทางเดียว)

> โจทย์: p₀ = 0.12 สงสัยว่า "สูงขึ้น" จาก 0.12 | n=250, x=45, α=0.05

**ขั้นที่ 1 — กำหนดสมมติฐาน** *(2 คะแนน)*
```
H₀ : p = 0.12
H₁ : p > 0.12         (ทางเดียว หางขวา เพราะโจทย์ถามว่า "สูงขึ้นหรือไม่")
```

**ขั้นที่ 2 — ระดับนัยสำคัญ** *(1 คะแนน)*
```
α = 0.05
```

**ขั้นที่ 3 — เลือกตัวสถิติทดสอบและเกณฑ์การตัดสินใจ** *(2 คะแนน)*
- ตัวแปรเป็นสัดส่วน (ชำรุด/ไม่ชำรุด) → ใช้ Z เสมอ

```
Z = (p̂ − p₀) / √(p₀q₀/n)          โดย q₀ = 1 − p₀ = 0.88
```
เกณฑ์ : ปฏิเสธ H₀ ถ้า p-value ≤ α (หรือ Z ≥ z₀.₀₅ = 1.645)

**ขั้นที่ 4 — คำนวณค่าสถิติและหาค่า p-value** *(3 คะแนน)*
```
p̂ = x/n = 45/250 = 0.18

SE = √(p₀q₀/n) = √( (0.12)(0.88)/250 ) = √(0.0004224) = 0.02055

Z = (0.18 − 0.12) / 0.02055 = 0.06/0.02055 = 2.92

p-value = P(Z > 2.92) = 1 − P(Z < 2.92) = 1 − 0.9982 = 0.0018
```

**ขั้นที่ 5 — ตัดสินใจและสรุปผล** *(2 คะแนน)*
```
Z = 2.92  >  z_crit = 1.645       (หรือ p-value = 0.0018 < α = 0.05)
∴ ปฏิเสธ H₀
```
**สรุป:** สัดส่วนสินค้าชำรุดหลังเปลี่ยนเครื่องจักรใหม่ (18%) **สูงขึ้นกว่า**ร้อยละ 12 เดิม อย่างมีนัยสำคัญทางสถิติที่ระดับ 0.05 — ฝ่ายควบคุมคุณภาพควรตรวจสอบเครื่องจักรใหม่นี้เพิ่มเติม
