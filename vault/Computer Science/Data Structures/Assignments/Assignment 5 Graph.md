# Assignment 5 – Graph

> [!info] กติกาที่ใช้
> - DFS / BFS: เมื่อมีโหนดให้เลือกหลายตัว เลือก **เลขน้อยก่อน** (เทียบกับการเลือกตามตัวอักษรในสไลด์)
> - MST / Shortest Path: ถ้าน้ำหนักเท่ากัน เลือกเส้นไหนก็ได้ (ระบุไว้ว่าเลือกเส้นใด)
> - กราฟมีน้ำหนัก ดังนั้น Adjacency Matrix ใส่ **ค่าน้ำหนัก** แทนเลข 1
> - Adjacency List เขียนในรูป `[โหนด|น้ำหนัก]`

**คำสั่ง**
1. จงหา Adjacency Matrix
2. จงหา Adjacency List
3. จงแสดงวิธีหาเส้นทางแบบ Depth-First เริ่มจากตำแหน่งที่ 1
4. จงแสดงวิธีหาเส้นทางแบบ Breadth-First เริ่มจากตำแหน่งที่ 1
5. จงแสดงวิธีหา Minimum Spanning Tree เริ่มที่จุด 1 (ระบุวิธีที่ใช้)
6. จงแสดงวิธีหา Shortest Path เริ่มจากจุด 1
